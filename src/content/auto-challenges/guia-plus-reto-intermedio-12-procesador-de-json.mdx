### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Dado un string JSON que contiene una lista de objetos, se debe filtrar según una propiedad y devolver solo los campos solicitados. **Ejemplo concreto:** entrada='[&#123;&quot;nombre&quot;:&quot;A&quot;,&quot;edad&quot;:25&#125;,&#123;&quot;nombre&quot;:&quot;B&quot;,&quot;edad&quot;:17&#125;]', min=18 → '[&#123;&quot;nombre&quot;:&quot;A&quot;,&quot;edad&quot;:25&#125;]'. **Edge cases:** JSON vacío, campo faltante, tipo de dato incorrecto.

### ⚙️ Paso 2: Implementación
**Implementación:** Parsear con json.loads (Python) o JSON.parse (JS). Filtrar con filter/condición y transformar con map. Devolver json.dumps/JSON.stringify.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)  
**Complejidad espacial:** O(n)  

**Complejidad:** O(n) tiempo, O(n) espacio. **Aplicaciones:** ETL, APIs REST, procesamiento de configuraciones, almacenamiento NoSQL.
