### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
def sol(s):
 st = []
 for c in s:
  if c == '(': st.append(c)
  elif not st or st.pop() != '(': return False
 return not st
```
