### 🚀 Paso 3: Complejidad y Optimización

O(n) tiempo, O(k) espacio para k elementos únicos.

### 💻 Código de la Solución (JavaScript)

```javascript
const sol = L => L.reduce((a, c) => ({...a, [c]: (a[c]||0)+1}), {});
```
