🏗️ Paso 1: Análisis

Necesitamos una estructura de datos dinámica (lista) para almacenar los nombres y una estructura de control (if/else) dentro de un ciclo para filtrar la información.
⚙️ Paso 2: Implementación

Usaremos el método .append() para modificar la lista en tiempo de ejecución y un bucle for para la iteración, optimizando la legibilidad con f-strings.
🚀 Paso 3: Optimización

Para que el código sea robusto, utilizaremos comparaciones de texto para asegurar que el sistema detecte al líder independientemente de la posición en la lista.
💻 Código de la Solución
```Python

# 1. Definición inicial de la banda
equipo = ["Nairobi", "Tokio", "Río"]

# 2. Incorporación de nuevo activo
equipo.append("Berlín")

# 3. Protocolo de identificación
print("--- ESCANEANDO PERFILES DE LA BANDA ---")
for miembro in equipo:
    if miembro == "Berlín":
        print(f"[!] LÍDER DETECTADO: {miembro} está al mando.")
    else:
        print(f"[-] Miembro confirmado: {miembro} listo para la acción.")
```
