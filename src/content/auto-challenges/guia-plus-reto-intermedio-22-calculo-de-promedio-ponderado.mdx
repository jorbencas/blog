### 🏗️ Paso 1: Análisis de la lógica

Sumar (valor * peso) y dividir por suma total de pesos.

### ⚙️ Paso 2: Implementación en Python

Garantizar que la suma de pesos no sea cero.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
def sol(L): num = sum(v*p for v,p in L); den = sum(p for v,p in L); return num/den if den else 0
```
