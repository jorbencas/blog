### 🏗️ Paso 1: Análisis de la lógica

Wrapper que almacena resultados previos en un dict y los reutiliza si la entrada se repite.

### ⚙️ Paso 2: Implementación en Python

Decorador que envuelve la función, consulta cache antes de ejecutar, guarda después.

### 🚀 Paso 3: Complejidad y Optimización

O(1) amortizado para llamadas repetidas, O(n) espacio en cache.

### 💻 Código de la Solución (Python)

```python
def memoize(f):
    cache = {}
    def w(*args):
        if args not in cache:
            cache[args] = f(*args)
        return cache[args]
    return w

@memoize
def fib(n):
    if n <= 1: return n
    return fib(n - 1) + fib(n - 2)

print(fib(50))

```
