### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** La limpieza de texto consiste en aplicar transformaciones como eliminar espacios múltiples, signos de puntuación, o normalizar a minúsculas. **Ejemplo concreto:** '  HOLA   MUNDO!  ' → 'hola mundo'. **Edge cases:** cadena vacía, solo símbolos, caracteres Unicode/acentos.

### ⚙️ Paso 2: Implementación
**Implementación:** Usar expresiones regulares para reemplazar patrones. En Python: `re.sub(r'[^a-z0-9\s]', '', s.lower()).strip()` seguido de `re.sub(r'\s+', ' ', s)`.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)  
**Complejidad espacial:** O(n)  

**Complejidad:** O(n) tiempo, O(n) espacio donde n es la longitud del texto. **Aplicaciones:** sanitización de input de usuarios, preparación de datos para NLP, limpieza de logs.
