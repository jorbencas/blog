### 🏗️ Paso 1: Análisis de la lógica

Uso de diccionario IP -> [Timestamps].

### ⚙️ Paso 2: Implementación en Python

Limpiar timestamps antiguos en cada chequeo.

### 🚀 Paso 3: Complejidad y Optimización

O(k) donde k es el límite por IP.

### 💻 Código de la Solución (Python)

```python
ips = {}; def sol(ip, limit=100):
 now = time.time(); h = ips.setdefault(ip, [])
 h[:] = [t for t in h if now - t < 60]
 if len(h) < limit: h.append(now); return True
 return False
```
