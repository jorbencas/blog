### 🏗️ Paso 1: Análisis de la lógica

Comprobar si n \>= min y n \<= max.

### ⚙️ Paso 2: Implementación en Python

En Python se puede simplificar como min \<= n \<= max.

### 🚀 Paso 3: Complejidad y Optimización

O(1).

### 💻 Código de la Solución (Python)

```python
def sol(n, mi, ma): return mi <= n <= ma
print(sol(5, 1, 10))
```
