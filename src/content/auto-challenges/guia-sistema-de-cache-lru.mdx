### 💻 Código de la Solución (Python)

```python
from collections import OrderedDict
class LRU:
 def __init__(self, cap): self.c = cap; self.m = OrderedDict()
 def get(self, k): 
  if k not in self.m: return -1
  self.m.move_to_end(k); return self.m[k]
 def put(self, k, v):
  if k in self.m: self.m.move_to_end(k)
  self.m[k] = v
  if len(self.m) > self.c: self.m.popitem(last=False)
```
