### 💻 Código de la Solución (Python)

```python
import hashlib
def h(f): return hashlib.md5(open(f,'rb').read()).hexdigest()
def sol(L): d={}; [d.setdefault(h(f),[]).append(f) for f in L]; return [v for v in d.values() if len(v)>1]
```
