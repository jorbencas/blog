### 🏗️ Paso 1: Análisis de la lógica

Suma (10-i)*digito % 11 == 0.

### ⚙️ Paso 2: Implementación en JavaScript

Ultimo dígito puede ser X (10).

### 🚀 Paso 3: Complejidad y Optimización

O(1).

### 💻 Código de la Solución (JavaScript)

```javascript
const sol = s => { s=s.replace(/-/g,''); if(s.length!==10) return false; let t=s.split('').reduce((a,c,i)=>a+(10-i)*(c==='X'?10:+c),0); return t%11===0; };
```
