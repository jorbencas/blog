Valida un número ISBN-10 o ISBN-13 según su algoritmo de checksum.

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** ISBN-10: la suma de (dígito × posición), módulo 11, debe dar 0. El último dígito puede ser 'X' (valor 10). ISBN-13: la suma ponderada (1,3,1,3...) debe ser múltiplo de 10. **Ejemplo concreto:** ISBN-10 0-306-40615-2 → check = (0×10+3×9+0×8+6×7+4×6+0×5+6×4+1×3+5×2+2×1) mod 11 = 0 → válido. **Edge cases:** ISBN con guiones/espacios, carácter X, longitud incorrecta.

### ⚙️ Paso 2: Implementación
**Implementación:** 1) Limpiar el string (eliminar guiones, espacios). 2) Verificar longitud (10 o 13). 3) Aplicar algoritmo según tipo. 4) Para ISBN-10, manejar X como 10.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)  
**Complejidad espacial:** O(1)  

**Complejidad:** O(n) tiempo, O(1) espacio. **Aplicaciones:** sistemas bibliotecarios, commerce de libros, validación de datos en formularios.

```python
def sol(s):
 s=s.replace('-',''); if len(s)!=10: return False
 total = sum((10-i)*(10 if c=='X' else int(c)) for i,c in enumerate(s))
 return total % 11 == 0
```
