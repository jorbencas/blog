# 🎯 Contador de Vocales

### 📝 Descripción del Reto

El objetivo de este reto es crear una función que reciba una cadena de texto y devuelva el número total de vocales (a, e, i, o, u) que contiene, sin importar si son mayúsculas o minúsculas.

### 🏗️ Paso 1: Análisis de la lógica
Podemos abordar este problema de varias formas:
1. Iterar por cada carácter y comprobar si es una vocal.
2. Utilizar expresiones regulares para buscar todas las vocales y contar las coincidencias.

### ⚙️ Paso 2: Implementación en Ruby
Ruby nos ofrece métodos muy potentes como `.count` o `.scan` con expresiones regulares.

### 💻 Código de la Solución (Ruby)

```ruby
def contar_vocales(cadena)
  # Usamos count con una cadena que contiene todas las vocales
  cadena.downcase.count("aeiouáéíóú")
end

# Casos de prueba
casos = ["Hola Mundo", "Retos de Programación", "AEIOU", "bcdfg"]

casos.each do |c|
  puts "▶ '#{c}' → #{contar_vocales(c)} vocales"
end
```
