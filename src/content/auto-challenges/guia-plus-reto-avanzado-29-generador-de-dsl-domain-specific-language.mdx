### 🏗️ Paso 1: Análisis de la lógica

Parsear comandos como 'SUMA 10 20' o 'RESTA 5 2'.

### ⚙️ Paso 2: Implementación en Python

Mapeo de palabras clave a operadores.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
def sol(txt):
 cmd, *args = txt.split(); a, b = map(int, args)
 if cmd == 'SUMA': return a + b
 if cmd == 'RESTA': return a - b
```
