### 🏗️ Paso 1: Análisis de la lógica

Crear una matriz de N x N con valores aleatorios (0/1).

### ⚙️ Paso 2: Implementación en Python

Dimensiones proporcionales a la longitud del texto.

### 🚀 Paso 3: Complejidad y Optimización

O(n^2).

### 💻 Código de la Solución (Python)

```python
import random
def sol(t): n=len(t)+4; return [[random.choice([0,1]) for _ in range(n)] for _ in range(n)]
```
