### 🏗️ Paso 1: Análisis de la lógica

Obtener cabeceras y unir valores con comas.

### ⚙️ Paso 2: Implementación en Python

Usar join() y manejo de saltos de línea.

### 🚀 Paso 3: Complejidad y Optimización

O(n*k).

### 💻 Código de la Solución (Python)

```python
def sol(L): h = ','.join(L[0].keys()); b = '\n'.join(','.join(map(str, d.values())) for d in L); return f'{h}\n{b}'
```
