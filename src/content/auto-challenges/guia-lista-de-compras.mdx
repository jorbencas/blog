# 🎯 Lista de Compras

### 📝 Descripción del Reto

El objetivo de este reto es gestionar una **Lista de Compras** sencilla. Deberás ser capaz de añadir elementos a la lista, borrarlos y comprobar si un elemento ya existe.

Este es un excelente ejercicio para practicar el uso de estructuras de datos básicas como `ArrayList` en Java.

### 🏗️ Paso 1: Uso de ArrayList
`ArrayList` es ideal aquí porque su tamaño es dinámico.

### ⚙️ Paso 2: Métodos de manipulación
1. `add()` para insertar.
2. `remove()` para eliminar.
3. `contains()` para buscar.

### 💻 Código de la Solución (Java)

```java
import java.util.ArrayList;
import java.util.List;

public class ListaCompras {
    private List<String> items;

    public ListaCompras() {
        this.items = new ArrayList<>();
    }

    public void agregar(String item) {
        items.add(item);
        System.out.println("➕ Añadido: " + item);
    }

    public void eliminar(String item) {
        if (items.remove(item)) {
            System.out.println("➖ Eliminado: " + item);
        }
    }

    public void mostrar() {
        System.out.println("🛒 Lista actual: " + items);
    }

    public static void main(String[] args) {
        ListaCompras miLista = new ListaCompras();
        miLista.agregar("Pan");
        miLista.agregar("Leche");
        miLista.agregar("Huevos");
        miLista.mostrar();
        miLista.eliminar("Leche");
        miLista.mostrar();
    }
}
```
