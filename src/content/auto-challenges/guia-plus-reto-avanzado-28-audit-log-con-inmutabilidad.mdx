### ⚙️ Paso 2: Implementación en Go

Garantiza que no se han borrado registros intermedios.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Go)

```go
import hashlib
log = []
def add(m): prev = log[-1]['h'] if log else '0'; h = hashlib.sha256(f'{prev}{m}'.encode()).hexdigest(); log.append({'m':m, 'h':h})
```
