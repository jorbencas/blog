# 🎯 Filtro de Spam por Keywords

### 📝 Descripción del Reto

En este reto, debes implementar un sistema básico de filtrado de spam. La función recibirá un mensaje (String) y una lista de palabras clave prohibidas (Keywords).

Si el mensaje contiene alguna de las palabras clave, debe ser marcado como "Spam". De lo contrario, se considerará "Seguro".

### 🏗️ Paso 1: Análisis de la lógica
La forma más eficiente es convertir el mensaje a minúsculas y verificar si alguna de las keywords está presente utilizando el método `.any?`.

### ⚙️ Paso 2: Implementación en Ruby
Ruby permite iterar sobre la lista de keywords y usar `.include?` para verificar la presencia en el mensaje.

### 💻 Código de la Solución (Ruby)

```ruby
def es_spam?(mensaje, keywords)
  mensaje_down = mensaje.downcase
  keywords.any? { |word| mensaje_down.include?(word.downcase) }
end

# Configuración
spam_keywords = ["oferta", "gana dinero", "gratis", "clic aquí"]

# Casos de prueba
mensajes = [
  "¡Gana dinero rápido haciendo clic aquí!",
  "Hola, ¿cómo va todo?",
  "Esta es una oferta increíble que no puedes perder"
]

mensajes.each do |msg|
  resultado = es_spam?(msg, spam_keywords) ? "🚫 SPAM" : "✅ SEGURO"
  puts "▶ [#{resultado}] - #{msg}"
end
```
