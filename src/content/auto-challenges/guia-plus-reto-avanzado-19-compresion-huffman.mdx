### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Huffman asigna códigos más cortos a caracteres más frecuentes. Se construye un árbol binario donde las hojas son caracteres con su frecuencia, y los caminos izquierda=0, derecha=1 forman el código. **Ejemplo concreto:** 'aaabbc' → frecuencias: a:3, b:2, c:1 → árbol con a='0', b='11', c='10' → comprimido: '000111110'. **Edge cases:** texto con un solo carácter repetido, caracteres con misma frecuencia, texto vacío, Unicode.

### ⚙️ Paso 2: Implementación
**Implementación:** 1) Contar frecuencias. 2) Construir cola de prioridad con nodos. 3) Fusionar los dos de menor frecuencia hasta que quede uno (el árbol). 4) Recorrer el árbol generando códigos. 5) Codificar el texto original con los códigos. 6) Decodificar recorriendo el árbol.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n log n)  
**Complejidad espacial:** O(n)  

**Complejidad:** O(n log n) para construir el árbol (usando heap). O(n) para codificar/decodificar. **Aplicaciones:** compresión de archivos (ZIP, gzip), códecs de imagen (JPEG), transmisión de datos.

```python
import heapq
def sol(txt):
 from collections import Counter
 f = Counter(txt); pq = [[v, [k, '']] for k,v in f.items()]
 heapq.heapify(pq)
 while len(pq) > 1:
  lo = heapq.heappop(pq); hi = heapq.heappop(pq)
  for p in lo[1:]: p[1] = '0' + p[1]
  for p in hi[1:]: p[1] = '1' + p[1]
  heapq.heappush(pq, [lo[0] + hi[0]] + lo[1:] + hi[1:])
 return sorted(heapq.heappop(pq)[1:], key=lambda p: (len(p[-1]), p))
```
