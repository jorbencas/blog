### 💻 Código de la Solución (Python)

```python
class Hist:
 def __init__(self): self.do, self.re = [], []
 def add(self, x): self.do.append(x); self.re = []
 def undo(self): 
  if self.do: self.re.append(self.do.pop())
 def redo(self): 
  if self.re: self.do.append(self.re.pop())
```
