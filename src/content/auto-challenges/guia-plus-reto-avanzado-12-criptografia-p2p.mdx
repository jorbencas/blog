### 🏗️ Paso 1: Análisis de la lógica

Generar llaves privadas y calcular pública: (g^a mod p).

### ⚙️ Paso 2: Implementación en Python

Secreto compartido = (B^a mod p).

### 🚀 Paso 3: Complejidad y Optimización

O(log exp).

### 💻 Código de la Solución (Python)

```python
def sol(g, p, a, b): A = pow(g, a, p); B = pow(g, b, p); return pow(B, a, p) == pow(A, b, p)
```
