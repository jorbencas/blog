# 🎯 Gestión de Inventario (OOP)

### 📝 Descripción del Reto

El objetivo de este reto es aplicar los principios de la **Programación Orientada a Objetos (OOP)** para gestionar un inventario de productos.

Deberás crear una clase `Producto` y una clase `Inventario`.
- La clase `Producto` debe tener propiedades como nombre, precio y cantidad.
- La clase `Inventario` debe permitir añadir productos, buscar un producto por nombre y calcular el valor total del inventario.

### 🏗️ Paso 1: Definición de la clase Producto
Creamos un constructor que inicialice las propiedades básicas del producto.

### ⚙️ Paso 2: Definición de la clase Inventario
Usaremos un array interno para almacenar instancias de `Producto` y métodos para manipularlo.

### 🚀 Paso 3: Métodos de utilidad
1. `agregarProducto(producto)`: Añade al array.
2. `buscarProducto(nombre)`: Usa `.find()`.
3. `calcularTotal()`: Usa `.reduce()`.

### 💻 Código de la Solución (JavaScript)

```javascript
class Producto {
  constructor(nombre, precio, cantidad) {
    this.nombre = nombre;
    this.precio = precio;
    this.cantidad = cantidad;
  }
}

class Inventario {
  constructor() {
    this.productos = [];
  }

  agregarProducto(producto) {
    this.productos.push(producto);
  }

  buscarProducto(nombre) {
    return this.productos.find(p => p.nombre.toLowerCase() === nombre.toLowerCase());
  }

  calcularTotal() {
    return this.productos.reduce((total, p) => total + (p.precio * p.cantidad), 0);
  }
}

// Ejemplo de uso
const miInventario = new Inventario();
miInventario.agregarProducto(new Producto("Laptop", 1200, 5));
miInventario.agregarProducto(new Producto("Mouse", 25, 10));
miInventario.agregarProducto(new Producto("Teclado", 45, 8));

console.log(`💰 Valor total del inventario: $${miInventario.calcularTotal()}`);
const p = miInventario.buscarProducto("Mouse");
console.log(`🔍 Producto encontrado: ${p ? `${p.nombre} ($${p.precio})` : "No encontrado"}`);
```
