### 🏗️ Paso 1: Análisis de la lógica

Convertir a cadena e iterar sumando los valores numéricos.

### ⚙️ Paso 2: Implementación en Python

Usar sum() con generador para mayor brevedad.

### 🚀 Paso 3: Complejidad y Optimización

O(d) tiempo, O(d) espacio para la cadena.

### 💻 Código de la Solución (Python)

```python
def sol(n): return sum(int(d) for d in str(abs(n)))
print(sol(1234))
```
