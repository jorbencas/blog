### 🏗️ Paso 1: Análisis de la lógica

Usar una lista interna para almacenar elementos.

### ⚙️ Paso 2: Implementación en Python

LIFO (Last In, First Out).

### 🚀 Paso 3: Complejidad y Optimización

O(1) para todas las operaciones.

### 💻 Código de la Solución (Python)

```python
class Pila:
 def __init__(self): self.s = []
 def push(self, v): self.s.append(v)
 def pop(self): return self.s.pop() if self.s else None
 def peek(self): return self.s[-1] if self.s else None
```
