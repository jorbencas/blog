### 🏗️ Paso 1: Análisis de la lógica

Mapear cada letra a su posición i + N en el alfabeto.

### ⚙️ Paso 2: Implementación en Python

Usar módulo 26 para rotar.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
def sol(t, n): res = ''; 
 for c in t: 
  if c.isalpha(): 
   base = ord('a') if c.islower() else ord('A')
   res += chr((ord(c)-base+n)%26+base)
  else: res += c
 return res
```
