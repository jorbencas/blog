### 🏗️ Paso 1: Análisis de la lógica

Usar una cola de prioridad para explorar el nodo con menor distancia.

### ⚙️ Paso 2: Implementación en Python

Relajar aristas actualizando distancias mínimas.

### 🚀 Paso 3: Complejidad y Optimización

O((V+E) log V).

### 💻 Código de la Solución (Python)

```python
import heapq
def sol(g, s):
 dist = {n: float('inf') for n in g}; dist[s] = 0
 pq = [(0, s)]
 while pq:
  d, u = heapq.heappop(pq)
  if d > dist[u]: continue
  for v, w in g[u].items():
   if dist[u] + w < dist[v]: dist[v] = dist[u] + w; heapq.heappush(pq, (dist[v], v))
 return dist
```
