### 🏗️ Paso 1: Análisis de la lógica

Limpiar texto, separar y meter en un Set.

### ⚙️ Paso 2: Implementación en Python

Uso de set() para unicidad.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
import re
def sol(txt): return len(set(re.findall(r'\w+', txt.lower())))
```
