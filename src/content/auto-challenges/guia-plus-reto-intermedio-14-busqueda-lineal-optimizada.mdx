### 🏗️ Paso 1: Análisis de la lógica

Si encuentra elemento en i > 0, swap con i-1.

### ⚙️ Paso 2: Implementación en JavaScript

Mejora búsquedas frecuentes.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (JavaScript)

```javascript
const sol = (L, x) => { let i=L.indexOf(x); if(i>0) [L[i], L[i-1]] = [L[i-1], L[i]]; return i; };
```
