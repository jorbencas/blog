### 🏗️ Paso 1: Análisis de la lógica

Nodos con left, right y val.

### ⚙️ Paso 2: Implementación en Python

Insertar recurriendo por el lado menor o mayor.

### 🚀 Paso 3: Complejidad y Optimización

O(log n) promedio, O(n) peor caso.

### 💻 Código de la Solución (Python)

```python
class Node:
    def __init__(self, v):
        self.val = v
        self.izq = None
        self.der = None

def insertar(root, v):
    if not root: return Node(v)
    if v < root.val:
        root.izq = insertar(root.izq, v)
    else:
        root.der = insertar(root.der, v)
    return root

def buscar(root, v):
    if not root: return False
    if root.val == v: return True
    if v < root.val: return buscar(root.izq, v)
    return buscar(root.der, v)

root = None
for v in [5, 3, 7, 2, 8]:
    root = insertar(root, v)
print(buscar(root, 7))
print(buscar(root, 4))
```
