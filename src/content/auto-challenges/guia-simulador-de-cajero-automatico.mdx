### 🏗️ Paso 1: Análisis de la lógica

Algoritmo Greedy: usar billetes más grandes primero.

### ⚙️ Paso 2: Implementación en C#

Billetes de 50, 20, 10, 5.

### 🚀 Paso 3: Complejidad y Optimización

O(1) (número finito de billetes).

### 💻 Código de la Solución (C#)

```csharp
def sol(amt):
 res = {}; bills = [50, 20, 10, 5]
 for b in bills:
  count = amt // b
  if count: res[b] = count; amt %= b
 return res
```
