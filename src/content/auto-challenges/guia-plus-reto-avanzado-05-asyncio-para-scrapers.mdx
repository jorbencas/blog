### 🏗️ Paso 1: Análisis de la lógica

Crear tareas asíncronas con asyncio. gather() y simular peticiones HTTP con asyncio.sleep().

### ⚙️ Paso 2: Implementación en Python

Usar async/await con asyncio.gather() para ejecutar múltiples peticiones concurrentes.

### 🚀 Paso 3: Complejidad y Optimización

O(n) tiempo secuencial optimizado a O(1) con concurrencia, O(n) memoria.

### 💻 Código de la Solución (Python)

```python
import asyncio

async def fetch(url):
    await asyncio.sleep(0.1)
    return f"Datos de {url}"

async def sol(urls):
    tareas = [fetch(u) for u in urls]
    return await asyncio.gather(*tareas)

urls = ["https://api.ejemplo.com/recurso/1",
        "https://api.ejemplo.com/recurso/2",
        "https://api.ejemplo.com/recurso/3"]
resultados = asyncio.run(sol(urls))
for r in resultados:
    print(r)

```
