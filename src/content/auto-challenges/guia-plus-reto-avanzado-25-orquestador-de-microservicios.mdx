### 🏗️ Paso 1: Análisis de la lógica

Si un servicio falla N veces, abrir el circuito y no llamar.

### ⚙️ Paso 2: Implementación en Python

Estado: CLOSED, OPEN, HALF_OPEN.

### 🚀 Paso 3: Complejidad y Optimización

O(1).

### 💻 Código de la Solución (Python)

```python
class CB:
 def __init__(self): self.fails = 0; self.open = False
 def call(self, f):
  if self.open: return 'error'
  try: return f()
  except: 
   self.fails += 1
   if self.fails > 3: self.open = True
   return 'error'
```
