### 🏗️ Paso 1: Análisis de la lógica

Iterar usando find() o regex.

### ⚙️ Paso 2: Implementación en Python

Loop while con start index.

### 🚀 Paso 3: Complejidad y Optimización

O(n*m).

### 💻 Código de la Solución (Python)

```python
def sol(s, sub): return [i for i in range(len(s)) if s.startswith(sub, i)]
```
