# 🎯 Desafío: Reto Inicial 18: Precio con IVA

### 📝 Descripción del Reto
Calcula el precio final de un producto aplicando un porcentaje de IVA. Dado el precio base y el porcentaje de IVA, devuelve el total.

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** El IVA se calcula como precio_base × (porcentaje / 100) y se suma al base. **Ejemplo concreto:** precio=100, IVA=21% → total = 100 + 100×0.21 = 121. **Edge cases:** IVA 0%, IVA 100%, precio negativo, porcentaje negativo.

### ⚙️ Paso 2: Implementación
**Implementación:** Función pura que recibe precio y porcentaje, calcula y devuelve el total. Se debe manejar precisión decimal para evitar errores de redondeo.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)  
**Complejidad espacial:** O(1)  

**Complejidad:** O(1). **Aplicaciones:** sistemas POS, carritos de compra, facturación electrónica, cálculos contables.
