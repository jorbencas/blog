### ⚙️ Paso 2: Implementación en Python

### 💻 Código de la Solución (Python)

```python
def s(t): h,m,ss=map(int,t.split(':')); return h*3600+m*60+ss
def sol(t1,t2): return abs(s(t1)-s(t2))
```
