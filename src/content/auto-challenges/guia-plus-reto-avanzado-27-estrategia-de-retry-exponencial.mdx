### 🏗️ Paso 1: Análisis de la lógica

En cada fallo, esperar 2^intento segundos.

### ⚙️ Paso 2: Implementación en Python

Añadir un factor de aleatoriedad (jitter) para evitar colisiones.

### 🚀 Paso 3: Complejidad y Optimización

O(log n) reintentos.

### 💻 Código de la Solución (Python)

```python
import time, random
def sol(f, max_r=5):
 for i in range(max_r):
  try: return f()
  except: time.sleep((2**i) + random.random())
 return 'error'
```
