### 🏗️ Paso 1: Análisis de la lógica

Iterar y usar startswith().

### ⚙️ Paso 2: Implementación en TypeScript

List comprehension para filtrar.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (TypeScript)

```typescript
def sol(L, l): return [w for w in L if w.lower().startswith(l.lower())]
print(sol(['Ana', 'Bea'], 'a'))
```
