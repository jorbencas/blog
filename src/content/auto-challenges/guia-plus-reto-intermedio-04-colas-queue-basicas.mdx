### 🏗️ Paso 1: Análisis de la lógica

Usar una lista o deque para inserción y extracción.

### ⚙️ Paso 2: Implementación en Go

FIFO (First In, First Out).

### 🚀 Paso 3: Complejidad y Optimización

O(1) con deque, O(n) con pop(0) en lista.

### 💻 Código de la Solución (Go)

```go
from collections import deque
class Cola:
 def __init__(self): self.q = deque()
 def add(self, v): self.q.append(v)
 def get(self): return self.q.popleft() if self.q else None
```
