# 🎯 Juego de Adivinar Número

### 📝 Descripción del Reto

El clásico **Juego de Adivinar el Número** consiste en que el programa genera un número aleatorio y el usuario debe intentar adivinarlo siguiendo pistas de "más alto" o "más bajo".

En este reto, deberás implementar la lógica principal del juego en Go.

### 🏗️ Paso 1: Generación Aleatoria
Usamos `math/rand` para generar un número entre 1 y 100.

### ⚙️ Paso 2: Bucle de Juego
Comparamos el intento del usuario con el número secreto y devolvemos la pista correspondiente.

### 💻 Código de la Solución (Go)

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

func jugar(intento int, secreto int) string {
	if intento < secreto {
		return "📈 ¡Más alto!"
	} else if intento > secreto {
		return "📉 ¡Más bajo!"
	}
	return "🎉 ¡Correcto! Has ganado."
}

func main() {
	rand.Seed(time.Now().UnixNano())
	numeroSecreto := rand.Intn(100) + 1
	intentos := []int{10, 50, 75, numeroSecreto}

	fmt.Println("🎮 Juego de Adivinar iniciado (1-100)")
	
	for _, intento := range intentos {
		resultado := jugar(intento, numeroSecreto)
		fmt.Printf("👉 Intento: %d | Resultado: %s\n", intento, resultado)
		if intento == numeroSecreto {
			break
		}
	}
}
```
