### 💻 Código de la Solución (Python)

```python
import re
def sol(xml):
 stack = []
 for tag, close in re.findall(r'<(/?)(\w+)>', xml):
  if not tag: stack.append(close)
  else: 
   if not stack or stack.pop() != close: return False
 return not stack
```
