### 🏗️ Paso 1: Análisis de la lógica

Usar expresiones regulares para el patrón.

### ⚙️ Paso 2: Implementación en Python

^(\+34|0034)?[6789]\d{8}$.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
import re
def sol(t): return bool(re.match(r'^(\+34|0034)?[6789]\d{8}$', t.replace(' ','')))
```
