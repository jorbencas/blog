# 🎯 Desafío: Reto Inicial 19: Descuento Simple

### 📝 Descripción del Reto
Aplica un descuento porcentual a un precio y devuelve el precio final. Similar al cálculo de IVA pero restando en vez de sumar.

### 🧪 Casos de Prueba

| Entrada | Salida esperada |
|---------|-----------------|
| `100, 15` | `85` |
| `200, 50` | `100` |
| `80, 0` | `80` |
| `50, 100` | `0` |

### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema:** Descuento = precio × (porcentaje / 100). Precio final = precio - descuento. **Ejemplo concreto:** precio=100, descuento=15% → final = 100 - 15 = 85. **Edge cases:** descuento 0%, descuento 100%, precio negativo.

### ⚙️ Paso 2: Implementación
**Implementación:** Una línea: `precio * (1 - descuento / 100)`. Importante: validar que el descuento esté entre 0 y 100.

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(1)  
**Complejidad espacial:** O(1)  

**Complejidad:** O(1). **Aplicaciones:** e-commerce, sistemas de promociones, liquidación de inventario.

### 💻 Código de la Solución
