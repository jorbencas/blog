### 🏗️ Paso 1: Análisis de la lógica

Registrar clases en un contenedor que resuelve automáticamente las dependencias al instanciar.

### ⚙️ Paso 2: Implementación en Python

Usar un diccionario como contenedor: registrar interfaz → implementación, resolver por tipo.

### 🚀 Paso 3: Complejidad y Optimización

O(1) registro, O(n) resolución de dependencias encadenadas.

### 💻 Código de la Solución (Python)

```python
class DI:
    def __init__(self): self._reg = {}

    def registrar(self, interfaz, impl):
        self._reg[interfaz] = impl

    def resolver(self, interfaz):
        return self._reg[interfaz]()

class Saludo:
    def ejecutar(self): return "Hola desde DI"

di = DI()
di.registrar(Saludo, lambda: Saludo())
s = di.resolver(Saludo)
print(s.ejecutar())

```
