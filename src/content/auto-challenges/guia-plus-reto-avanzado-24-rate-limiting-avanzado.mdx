### 🏗️ Paso 1: Análisis de la lógica

Recargar tokens por tiempo transcurrido, retirar al consumir.

### ⚙️ Paso 2: Implementación en Dart

Validar si bucket tiene tokens.

### 🚀 Paso 3: Complejidad y Optimización

O(1).

### 💻 Código de la Solución (Dart)

```dart
import time
class TB:
 def __init__(self, r, c): self.r, self.c, self.t, self.last = r, c, c, time.time()
 def allow(self): 
  now = time.time(); self.t = min(self.c, self.t + (now - self.last)*self.r)
  self.last = now
  if self.t >= 1: self.t -= 1; return True
  return False
```
