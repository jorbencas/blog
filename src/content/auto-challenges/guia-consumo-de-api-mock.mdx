### 🏗️ Paso 1: Análisis de la lógica

Crear estructura mock que simule respuesta HTTP con datos precargados.

### ⚙️ Paso 2: Implementación en Python

Función que devuelve un dict con status y data simulados.

### 🚀 Paso 3: Complejidad y Optimización

O(n) tiempo y espacio, donde n es la cantidad de datos mock generados.

### 💻 Código de la Solución (Python)

```python
import json

def sol():
    return {"status": "ok", "data": [{"id": i, "nombre": f"Item {i}"} for i in range(5)]}

respuesta = sol()
print(json.dumps(respuesta, indent=2))

```
