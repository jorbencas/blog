# 🎯 Decorador de Medición de Tiempo

### 📝 Descripción del Reto

En programación, un **Decorador** (o un wrapper) es una función que envuelve a otra para añadirle alguna funcionalidad extra sin modificar su código original.

Tu objetivo es crear una función en Go que reciba otra función como argumento, la ejecute y mida cuánto tiempo tarda en completarse, imprimiendo el resultado en consola.

### 🏗️ Paso 1: Funciones de Orden Superior
En Go, las funciones son ciudadanos de primera clase, lo que significa que pueden pasarse como argumentos.

### ⚙️ Paso 2: Medición de Tiempo
Usamos el paquete `time` para capturar el instante antes y después de la ejecución: `time.Now()` y `time.Since()`.

### 💻 Código de la Solución (Go)

```go
package main

import (
	"fmt"
	"time"
)

// Decorador que envuelve una función y mide su tiempo
func medirTiempo(f func()) {
	inicio := time.Now()
	f()
	fmt.Printf("⏱️ Tiempo de ejecución: %v\n", time.Since(inicio))
}

func tareaPesada() {
	fmt.Println("⏳ Procesando algo pesado...")
	time.Sleep(1500 * time.Millisecond) // Simulamos espera
}

func main() {
	fmt.Println("🚀 Iniciando tarea decorada:")
	medirTiempo(tareaPesada)
}
```
