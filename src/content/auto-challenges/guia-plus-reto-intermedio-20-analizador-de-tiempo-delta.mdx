### 🏗️ Paso 1: Análisis de la lógica

Usar datetime en Python o Date en JS.

### 🚀 Paso 3: Complejidad y Optimización

### 💻 Código de la Solución (Python)

```python
from datetime import datetime
def sol(f1, f2): d1=datetime.strptime(f1,'%Y-%m-%d'); d2=datetime.strptime(f2,'%Y-%m-%d'); return abs((d2-d1).days)
```
