# 🎯 Reto Avanzado 06: Middleware de Seguridad

### 📝 Descripción del Reto

En el desarrollo web, un **Middleware** es una pieza de código que se ejecuta entre una petición y la respuesta final, permitiendo interceptar, modificar o validar la solicitud.

Tu objetivo es implementar un sistema de **Middleware de Seguridad** que verifique si una petición contiene un token de autenticación válido (`"SECRET_TOKEN"`) antes de permitir el acceso al recurso.

### 🏗️ Paso 1: Interfaz Middleware
Definimos una interfaz con un método para procesar la petición y pasarla al siguiente elemento en la cadena.

### ⚙️ Paso 2: Implementación concreta
Creamos el `AuthMiddleware` que comprueba el encabezado `"Authorization"`.

### 🚀 Paso 3: Cadena de Responsabilidad
El middleware puede estar encadenado, permitiendo ejecutar múltiples validaciones secuencialmente.

### 💻 Código de la Solución (Java)

```java
import java.util.HashMap;
import java.util.Map;

interface Middleware {
    boolean handle(Map<String, String> request);
}

class AuthMiddleware implements Middleware {
    private static final String VALID_TOKEN = "SECRET_TOKEN";

    @Override
    public boolean handle(Map<String, String> request) {
        String token = request.get("Authorization");
        if (token != null && token.equals(VALID_TOKEN)) {
            System.out.println("✅ Autenticación exitosa.");
            return true;
        }
        System.out.println("❌ Error: Token no válido o ausente.");
        return false;
    }
}

public class SistemaSeguridad {
    public static void main(String[] args) {
        AuthMiddleware auth = new AuthMiddleware();

        // Caso 1: Petición válida
        Map<String, String> reqValida = new HashMap<>();
        reqValida.put("Authorization", "SECRET_TOKEN");
        System.out.println("Petición 1: " + (auth.handle(reqValida) ? "ACCESO PERMITIDO" : "ACCESO DENEGADO"));

        // Caso 2: Petición inválida
        Map<String, String> reqInvalida = new HashMap<>();
        reqInvalida.put("Authorization", "token_falso");
        System.out.println("Petición 2: " + (auth.handle(reqInvalida) ? "ACCESO PERMITIDO" : "ACCESO DENEGADO"));
    }
}
```
