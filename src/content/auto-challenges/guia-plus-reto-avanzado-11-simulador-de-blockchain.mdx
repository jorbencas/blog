### 🏗️ Paso 1: Análisis de la lógica

Cada bloque contiene hash del anterior y un nonce.

### ⚙️ Paso 2: Implementación en Ruby

Calcular SHA256 hasta cumplir dificultad.

### 🚀 Paso 3: Complejidad y Optimización

O(2^dificultad).

### 💻 Código de la Solución (Ruby)

```ruby
import hashlib
def hash_b(b): return hashlib.sha256(str(b).encode()).hexdigest()
def mine(b, d): 
 while not hash_b(b).startswith('0'*d): b['nonce']+=1
 return b
```
