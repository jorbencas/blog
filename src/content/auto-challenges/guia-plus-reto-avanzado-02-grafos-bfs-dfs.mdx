# 🎯 Reto Avanzado 02: Grafos (BFS/DFS)

### 📝 Descripción del Reto

El objetivo de este reto es implementar dos de los algoritmos de recorrido de grafos más fundamentales: **BFS (Breadth-First Search)** y **DFS (Depth-First Search)**.

Deberás crear una función que, dado un grafo (representado como una lista de adyacencia) y un nodo inicial, devuelva el orden en que se visitan los nodos utilizando ambos métodos.

- **BFS**: Utiliza una cola para explorar los vecinos nivel por nivel.
- **DFS**: Utiliza una pila (o recursividad) para explorar lo más profundo posible antes de retroceder.

### 🏗️ Paso 1: Representación del Grafo
Usaremos un objeto de JavaScript para representar la lista de adyacencia, donde cada clave es un nodo y su valor es un array de nodos conectados.

### ⚙️ Paso 2: Implementación de BFS
1. Creamos una cola y añadimos el nodo inicial.
2. Usamos un conjunto (`Set`) para registrar los nodos visitados.
3. Mientras la cola no esté vacía:
   - Extraemos el primer nodo.
   - Si no ha sido visitado, lo marcamos y añadimos sus vecinos no visitados a la cola.

### ⚙️ Paso 3: Implementación de DFS (Iterativo)
Similar a BFS, pero usamos una pila (stack) en lugar de una cola.

### 💻 Código de la Solución (JavaScript)

```javascript
const grafo = {
  'A': ['B', 'C'],
  'B': ['A', 'D', 'E'],
  'C': ['A', 'F'],
  'D': ['B'],
  'E': ['B', 'F'],
  'F': ['C', 'E']
};

function bfs(grafo, inicio) {
  const visitados = new Set();
  const cola = [inicio];
  const orden = [];

  while (cola.length > 0) {
    const nodo = cola.shift();
    if (!visitados.has(nodo)) {
      visitados.add(nodo);
      orden.push(nodo);
      cola.push(...grafo[nodo].filter(n => !visitados.has(n)));
    }
  }
  return orden;
}

function dfs(grafo, inicio) {
  const visitados = new Set();
  const pila = [inicio];
  const orden = [];

  while (pila.length > 0) {
    const nodo = pila.pop();
    if (!visitados.has(nodo)) {
      visitados.add(nodo);
      orden.push(nodo);
      // Invertimos para mantener el orden de inserción visual si es necesario
      pila.push(...grafo[nodo].filter(n => !visitados.has(n)).reverse());
    }
  }
  return orden;
}

console.log("🚀 Recorrido BFS:", bfs(grafo, 'A')); // ['A', 'B', 'C', 'D', 'E', 'F']
console.log("🚀 Recorrido DFS:", dfs(grafo, 'A')); // ['A', 'B', 'D', 'E', 'F', 'C']
```
