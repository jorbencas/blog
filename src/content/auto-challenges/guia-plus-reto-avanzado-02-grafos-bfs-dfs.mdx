### 🏗️ Paso 1: Análisis de la lógica
**Análisis del problema: Reto Avanzado 02: Grafos (BFS/DFS)**

Antes de escribir código, es fundamental entender qué se nos pide. Sigamos estos pasos:

1. **Identificar la entrada**: ¿qué datos recibe el programa? ¿vienen en un formato específico? ¿pueden estar vacíos o ser nulos?

2. **Definir la salida**: ¿qué debe devolver exactamente? ¿un valor booleano, un número, una cadena, una estructura más compleja?

3. **Caso de ejemplo**: probemos con un ejemplo concreto. Aplicamos la lógica manualmente para verificar que entendemos el flujo correcto.

4. **Edge cases a considerar**:
   - Entrada vacía o nula
   - Valores en los límites del rango permitido
   - Datos con formato inesperado
   - Volumen grande de datos (rendimiento)

5. **Estrategia de solución**: basado en el análisis, seleccionamos el algoritmo más adecuado. ¿Es un problema de búsqueda? ¿ordenación? ¿transformación? ¿procesamiento secuencial?

### 🚀 Paso 3: Complejidad y Optimización

**Complejidad temporal:** O(n)  
**Complejidad espacial:** O(n)  

**Análisis de complejidad y optimización**

**Complejidad temporal:**
Evalúa cómo crece el tiempo de ejecución al aumentar el tamaño de la entrada. Para la mayoría de soluciones, una complejidad O(n) es aceptable, donde n es el tamaño de la entrada. Si tu solución es O(n²), considera si se puede optimizar.

**Complejidad espacial:**
¿Cuánta memoria adicional utiliza tu algoritmo? ¿Creas copias de los datos o trabajas in-place? En general, O(n) adicional es aceptable para la mayoría de aplicaciones.

**Posibles optimizaciones:**
- ¿Se puede reducir la complejidad con una estructura de datos diferente?
- ¿Conviene usar iteración en vez de recursión para ahorrar pila de llamadas?
- ¿Existe alguna función de la librería estándar que ya resuelva parte del problema?
- ¿Se puede aplicar early exit para evitar trabajo innecesario?

**Aplicaciones en el mundo real:**
Este patrón de solución aparece frecuentemente en:
- Procesamiento de datos y pipelines ETL
- APIs REST y servicios web
- Análisis de logs y métricas
- Automatización de tareas y scripting
- Validación y transformación de datos en sistemas de información

### 💻 Código de la Solución (JavaScript)

```javascript
const grafo = {
  'A': ['B', 'C'],
  'B': ['A', 'D', 'E'],
  'C': ['A', 'F'],
  'D': ['B'],
  'E': ['B', 'F'],
  'F': ['C', 'E']
};

function bfs(grafo, inicio) {
  const visitados = new Set();
  const cola = [inicio];
  const orden = [];

  while (cola.length > 0) {
    const nodo = cola.shift();
    if (!visitados.has(nodo)) {
      visitados.add(nodo);
      orden.push(nodo);
      cola.push(...grafo[nodo].filter(n => !visitados.has(n)));
    }
  }
  return orden;
}

function dfs(grafo, inicio) {
  const visitados = new Set();
  const pila = [inicio];
  const orden = [];

  while (pila.length > 0) {
    const nodo = pila.pop();
    if (!visitados.has(nodo)) {
      visitados.add(nodo);
      orden.push(nodo);
      // Invertimos para mantener el orden de inserción visual si es necesario
      pila.push(...grafo[nodo].filter(n => !visitados.has(n)).reverse());
    }
  }
  return orden;
}

console.log("🚀 Recorrido BFS:", bfs(grafo, 'A')); // ['A', 'B', 'C', 'D', 'E', 'F']
console.log("🚀 Recorrido DFS:", dfs(grafo, 'A')); // ['A', 'B', 'D', 'E', 'F', 'C']
```
