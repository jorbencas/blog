### 💻 Código de la Solución (Python)

```python
import hmac, hashlib, base64
def sol(t, s):
 p, sig = t.rsplit('.', 1)
 exp_sig = hmac.new(s.encode(), p.encode(), hashlib.sha256).digest()
 return sig == base64.b64encode(exp_sig).decode()
```
