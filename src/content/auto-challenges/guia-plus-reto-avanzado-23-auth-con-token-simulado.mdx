### 🏗️ Paso 1: Análisis de la lógica

Header.Payload.Signature. Hashing de H+P con secreto.

### ⚙️ Paso 2: Implementación en Python

HMAC SHA256.

### 🚀 Paso 3: Complejidad y Optimización

O(n).

### 💻 Código de la Solución (Python)

```python
import hmac, hashlib, base64
def sol(t, s):
 p, sig = t.rsplit('.', 1)
 exp_sig = hmac.new(s.encode(), p.encode(), hashlib.sha256).digest()
 return sig == base64.b64encode(exp_sig).decode()
```
