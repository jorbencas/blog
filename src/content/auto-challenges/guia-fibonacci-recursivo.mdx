### 🏗️ Paso 1: Análisis de la lógica

Caso base: fib(0) = 0, fib(1) = 1. Caso recursivo: fib(n) = fib(n-1) + fib(n-2).

### ⚙️ Paso 2: Implementación en Python

Función recursiva con condición base y llamadas anidadas.

### 🚀 Paso 3: Complejidad y Optimización

O(2^n) tiempo, O(n) espacio en pila de llamadas.

### 💻 Código de la Solución (Python)

```python
def sol(n):
    if n <= 1: return n
    return sol(n - 1) + sol(n - 2)

for n in [0, 1, 5, 10, 20]:
    print(f"fib({n}) = {sol(n)}")

```
