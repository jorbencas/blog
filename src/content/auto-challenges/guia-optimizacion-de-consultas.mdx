### 🏗️ Paso 1: Análisis de la lógica

Dada una lista de registros con id y valor, filtrar los que están dentro de un rango [min, max].

### ⚙️ Paso 2: Implementación en Python

Recorrer la lista con una comprensión y aplicar el filtro por rango.

### 🚀 Paso 3: Complejidad y Optimización

O(n) tiempo, O(k) espacio (k = resultados filtrados).

### 💻 Código de la Solución (Python)

```python
def sol(datos, min_v, max_v):
    return [d for d in datos if min_v <= d["valor"] <= max_v]

datos = [{"id": i, "valor": i * 5} for i in range(200)]
resultado = sol(datos, 50, 150)
print(f"Registros en rango: {len(resultado)}")

```
