### 🏗️ Paso 1: Análisis de la lógica

Definir esquema como dict de campo → tipo. Verificar cada campo del JSON contra el esquema.

### ⚙️ Paso 2: Implementación en Python

Recorrer el esquema, validar existencia del campo y tipo con isinstance().

### 🚀 Paso 3: Complejidad y Optimización

O(n) tiempo, O(1) espacio, donde n es el número de campos en el esquema.

### 💻 Código de la Solución (Python)

```python
def sol(datos, esquema):
    errores = []
    for campo, tipo in esquema.items():
        if campo not in datos:
            errores.append(f"Falta '{campo}'")
        elif not isinstance(datos[campo], tipo):
            errores.append(f"'{campo}' debe ser {tipo.__name__}")
    return errores if errores else "Válido"

esquema = {"nombre": str, "edad": int, "activo": bool}
datos = {"nombre": "Ana", "edad": 30, "activo": True}
print(sol(datos, esquema))

```
