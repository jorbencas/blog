# Guía de JavaScript: De 0 a 100

## 🛠️ Requisitos e Instalación

**Windows/macOS:** Descarga [Node.js](https://nodejs.org/) (LTS). Incluye `npm`.
**Linux:** `curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash - && sudo apt install nodejs`
**Verificación:** `npm` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **npm** para paquetes, **npx** para ejecutar binarios. Alternativa: **bun** o **pnpm**. Editores: VSCode, WebStorm.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Variables y Tipos:** `let` (mutable) y `const` (inmutable). Evita `var`. Primitivos: string, number, boolean, null, undefined, symbol, bigint. Usa `===` para comparación estricta.
- **Funciones:** Función clásica: `function suma(a, b) { return a + b; }`. Arrow: `const suma = (a, b) => a + b;`. Las funciones son ciudadanos de primera clase.
- **Objetos y Arrays:** Objetos: `const user = { nombre: "Ana", edad: 30 }`. Arrays: `const nums = [1, 2, 3]`. Métodos: `.map()`, `.filter()`, `.reduce()`. Spread: `[...arr]`, `{...obj}`.
- **Asincronía:** Callbacks → Promesas (`fetch(url).then(r => r.json())`) → Async/await (`const data = await fetch(url)`). El event loop gestiona la concurrencia en un solo hilo.
- **Módulos:** ES Modules: `export` / `import`. CommonJS (legacy Node): `module.exports` / `require()`. Usa ES modules en proyectos modernos (`"type": "module"` en package.json).

## 🏗️ Frameworks Populares

### React
**Instalación:** `npx create-react-app mi-app  # o: npm create vite@latest mi-app -- --template react`
Biblioteca para UI basada en componentes. Virtual DOM para renderizado eficiente. Hooks (`useState`, `useEffect`) para estado y efectos secundarios.
```javascript
function Saludo({ nombre }) {
  return <h1>Hola, {nombre}!</h1>;
}

export default function App() {
  return <Saludo nombre="Mundo" />;
}
```
### Express
**Instalación:** `npm init -y && npm install express`
Framework web minimalista para Node.js. Middleware-based, gran ecosistema. Alternativas modernas: Fastify, Hono.
```javascript
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.json({ mensaje: 'Hola Mundo' });
});

app.listen(3000);
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Usa `===` en lugar de `==` para comparaciones estrictas.
- Mantén las funciones puras cuando sea posible (misma entrada → misma salida).
- Usa `const` por defecto, `let` solo cuando necesites reasignar.
- Evita modificar el DOM directamente — usa frameworks o `innerHTML` con precaución.
- Usa `try/catch` con async/await para manejo de errores.
- Implementa debounce/throttle para eventos frecuentes (scroll, input).

**Complejidad algorítmica (Big O):**

Arrays: acceso O(1), búsqueda O(n), push/pop O(1), shift/unshift O(n). Objetos/Map: O(1) promedio. `sort()` O(n log n).
