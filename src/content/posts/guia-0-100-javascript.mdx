# Guía de JavaScript: De 0 a 100

JavaScript es el lenguaje esencial para la interactividad en la web y mucho más con Node.js.

## 🛠️ Requisitos e Instalación

1. Instalar Node.js desde nodejs.org.
2. Incluir etiquetas <script> en HTML o ejecutar archivos .js con `node`.

## 🚀 Hola Mundo y Sintaxis Básica

```javascript
console.log("Hola Mundo");
```

Sintaxis basada en C. Usa `let` y `const` para variables.

## 🏗️ Frameworks Populares

### React

**Instalación:**
```bash
npx create-react-app my-app
```

**Estructura Principal:**
Arquitectura basada en componentes funcionales y Hooks.

## 📝 Ejercicios Prácticos

1. **Contador**: Haz un script que cuente hasta 100 en consola.
2. **DOM**: Cambia el color de un botón al hacer click.
3. **Fetch API**: Obtén datos de una API pública y muéstralos.
