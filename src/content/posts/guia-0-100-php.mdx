# Guía de PHP: De 0 a 100

PHP es un lenguaje de script del lado del servidor diseñado para el desarrollo web.

## 🛠️ Requisitos e Instalación

1. Instalar XAMPP o PHP directo en Linux.
2. Probar con `php -v`.

## 🚀 Hola Mundo y Sintaxis Básica

```php
<?php echo "Hola Mundo"; ?>
```

Variables empiezan por `$`. Débilmente tipado (aunque moderno permite tipos).

## 🏗️ Frameworks Populares

### Laravel

**Instalación:**
```bash
composer global require laravel/installer
```

**Estructura Principal:**
Patrón MVC elegante, Eloquent ORM y Blade como motor de plantillas.

## 📝 Ejercicios Prácticos

1. **Array Map**: Aplica una función a todos los elementos de un array.
2. **Formulario**: Recibe datos de un POST y muéstralos por pantalla.
3. **Migrations**: Define una tabla simple en Laravel usando migraciones.
