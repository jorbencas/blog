# Guía de C# y .NET: De 0 a 100

C# es el lenguaje principal de Microsoft, diseñado para la plataforma .NET moderna.

## 🛠️ Requisitos e Instalación

1. Instalar el SDK de .NET desde dotnet.microsoft.com.

## 🚀 Hola Mundo y Sintaxis Básica

```csharp
System.Console.WriteLine("Hola Mundo");
```

Similar a Java pero con características modernas como LINQ y async/await nativo.

## 🏗️ Frameworks Populares

### ASP.NET Core

**Instalación:**
```bash
dotnet new webapi
```

**Estructura Principal:**
Sistema de inyección de dependencias integrado y middleware HTTP.

## 📝 Ejercicios Prácticos

1. **LINQ**: Realiza una consulta sobre una lista de objetos usando sintaxis fluida.
2. **Enums**: Usa enumeraciones para definir estados de un pedido.
3. **Dapper**: Acceso básico a base de datos usando este Micro-ORM.
