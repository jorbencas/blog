# Guía de C# y .NET: De 0 a 100

## 🛠️ Requisitos e Instalación

**Todas las plataformas:** Descarga .NET SDK desde [dotnet.microsoft.com](https://dotnet.microsoft.com/download). Incluye runtime, compilador y CLI (`dotnet`).
**Linux (apt):** `sudo apt install dotnet-sdk-8.0` — añade repo Microsoft primero.
**Verificación:** `dotnet` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **Visual Studio** (Windows) o **VS Code** + C# Dev Kit. **NuGet** para paquetes. **dotnet format** para estilo.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Programa Principal:** `Console.WriteLine("Hola Mundo");` — top-level statements desde C# 9 (sin `class Program`). Namespaces con `using System;`.
- **Tipos y Records:** Primitivos: `int`, `long`, `double`, `decimal`, `bool`, `string`. `var` para inferencia. Nullable: `int? edad = null`. `record Persona(string Nombre, int Edad)`.
- **LINQ:** `numeros.Where(n => n > 5).OrderBy(n => n).Select(n => n * 2)`. Sintaxis query: `from n in numeros where n > 5 select n`. Lazy evaluation.
- **Async/Await:** `async Task<int> FetchAsync() { var data = await http.GetStringAsync(url); ... }`. `Task<T>` para operaciones asíncronas. Evita `.Result`.
- **POO Moderno:** Propiedades: `public string Nombre { get; set; }`. Primary constructors (C# 12). Pattern matching: `if (p is Persona { Edad: >= 18 })`.

## 🏗️ Frameworks Populares

### ASP.NET Core
**Instalación:** `dotnet new webapi -o MiApi`
Framework web multiplataforma. Minimal APIs (C# 6+) y controladores. Incluye DI, middleware, autenticación y OpenAPI.
```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hola Mundo");

app.Run();
```
### Entity Framework Core
**Instalación:** `dotnet add package Microsoft.EntityFrameworkCore.Sqlite`
ORM moderno. Code-first, migraciones, lazy loading. Soporta SQL Server, SQLite, PostgreSQL, MySQL.
```csharp
public class BlogContext : DbContext {
    public DbSet<Post> Posts => Set<Post>();
}

public record Post(int Id, string Titulo, string Contenido);
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Usa `record` para modelos de datos inmutables.
- Prefiere `async Task` sobre `async void` (excepto event handlers).
- Configura nullable reference types (`<Nullable>enable</Nullable>`) desde el inicio.
- Usa `StringBuilder` para concatenaciones en bucles grandes.
- Implementa `IEquatable<T>` para comparaciones personalizadas.

**Complejidad algorítmica (Big O):**

List&lt;T&gt;: acceso O(1), inserción O(n). Dictionary&lt;K,V&gt;: O(1) promedio. HashSet&lt;T&gt;: O(1). LINQ Where/Select: O(n). OrderBy: O(n log n). GroupBy: O(n).
