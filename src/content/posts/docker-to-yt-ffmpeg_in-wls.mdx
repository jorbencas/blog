## 1. El docker-compose.yml

Guarda los vídeos en tu disco de Windows <code>(C:)</code> para abrirlos con el reproductor de Windows. En WSL, tu disco <code>C:</code> está montado en <code>/mnt/c/</code>.

```yaml
services:
  downloader:
    image: alpine:latest
    container_name: yt_ffmpeg_downloader
    volumes:
      - /mnt/c/Users/TuUsuario/Videos/test_videos:/test_videos
    working_dir: /test_videos
    user: root
    tty: true
    stdin_open: true
    command: >-
      sh -c "apk update &&
      apk add --no-cache ffmpeg bash python3 py3-pip &&
      pip install --break-system-packages yt-dlp &&
      id -u jorge >/dev/null 2>&1 || adduser -D -u 1000 jorge &&
      chown -R jorge:jorge /test_videos &&
      su-exec jorge bash midu.sh"
```

> **Sobre `tty` e `stdin_open`:** Equivalen a `-it` en `docker run`. Sin ellas, no podrías escribir comandos dentro.

> **Sobre los permisos:** `user: root` para instalar paquetes, `su-exec` para ejecutar como tu usuario real. Cambia `jorge` por tu nombre de usuario (`whoami`).

> **Ojo:** Cambia `TuUsuario` por el nombre real de tu usuario en Windows (`ls /mnt/c/Users/`).

## 2. midu.sh v5.0.0 — Conversor, descargador y editor de vídeo

Script CLI con **20 modos** independientes, menú interactivo, presets de calidad, detección de GPU, progreso en tiempo real y **configuración guardada por modo** en <code>conf.json</code>.

Después de seleccionar el modo, el script:

1. **Selecciona el(los) vídeo(s)** — Lista los archivos disponibles. Si solo hay 1, se selecciona automáticamente. Si hay varios, puedes elegir: `1,3,5` (lista), `1-5` (rango) o `all` (todos)
2. **Elige directorio de salida** — O crea uno nuevo
3. **Pide nombre de salida** — Si seleccionaste 1 archivo. Si son varios, cada uno mantiene su nombre
4. **Configura parámetros** — Opciones específicas de cada modo
5. **Procesa en paralelo** — Usa los threads configurados para procesar varios archivos a la vez
6. **Guarda la config** — Para la próxima vez carga automáticamente

### Selección múltiple de archivos

En modos como convertir, GIF, rotar, etc., puedes seleccionar varios archivos a la vez:

```
  Vídeos disponibles:

     1) video1.mkv (150MB)
     2) video2.mkv (230MB)
     3) video3.mkv (180MB)
     4) video4.mkv (95MB)

  Ejemplo: 1,3,5 o 1-5 o 'all' para todos
  → Selecciona: 1,3
  → Seleccionados: 2 archivo(s)
    → video1.mkv
    → video3.mkv
```

**Formatos de selección:**
- `1,3,5` — Lista de archivos específicos
- `1-4` — Rango del 1 al 4
- `all` o `a` — Todos los archivos
- `3` — Solo un archivo (si solo hay 1, se selecciona automáticamente)

Los archivos se procesan en paralelo usando los threads configurados.

```bash
# Descargar

./midu.sh --thumbnail --thumbnail-time 00:01:30

./midu.sh --info

./midu.sh --rotate 90

./midu.sh --crop 640:480

./midu.sh --fade 2

./midu.sh --normalize
```

### Validación de URLs

Al intentar descargar, el script comprueba si la URL es soportada antes de empezar. Si no lo es, avisa con un mensaje claro:

```
  Comprobando URL...
ERROR: URL no soportada o no válida
  yt-dlp no puede descargar de este sitio
  Lista: https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md
```

Esto evita esperar a que yt-dlp falle al descargar.

### Modos de corte avanzados

El modo `--cut` tiene 3 sub-modos:

**1. Cortar un trozo** (normal) — Mantiene solo el segmento indicado:
```bash
./midu.sh --cut -ss 00:01:30 -e 00:03:45
```

**2. Eliminar secciones** (`--remove`) — Quita las partes indicadas del vídeo:
```bash
./midu.sh --cut --remove -clips 00:01:00-00:02:30,00:05:00-00:07:15
```
Esto elimina los trozos del 1:00-2:30 y del 5:00-7:15, uniendo el resto.

**3. Extraer clips** (`--extract`) — Saca varios trozos y los une en un solo vídeo:
```bash
./midu.sh --cut --extract -clips 00:01:00-00:02:30,00:05:00-00:07:15
```
Esto extrae los dos clips y los concatena en un único archivo.

En el menú interactivo, al seleccionar "Cortar vídeo", aparecen las 3 opciones:
```
  Tipo de corte
    1) Cortar un trozo     — Mantener solo ese trozo
    2) Eliminar secciones  — Quitar partes del vídeo
    3) Extraer clips       — Sacar varios trozos y unirlos
```

### Nuevos modos de edición de vídeo

**Estabilizar** — Quitar el temblor de vídeos grabados a mano:
```bash
./midu.sh --stabilize              # Estabilización normal (shakiness=5)
./midu.sh --stabilize 8            # Estabilización fuerte
```

**Ajustar imagen** — Brillo, contraste, saturación y gamma:
```bash
./midu.sh --adjust brightness=0.1 contrast=1.2 saturation=0.8
./midu.sh --adjust gamma=1.5       # Aclarar vídeo oscuro
```

**Censurar** — Pixelar regiones del vídeo (caras, matrículas):
```bash
./midu.sh --censor 100:50:200:150                    # Una región
./midu.sh --censor 100:50:200:150 300:100:150:100    # Varias regiones
```

**Denoise y Sharpen** — Mejorar calidad de vídeos viejos:
```bash
./midu.sh --denoise 50    # Reducir ruido (1-100)
./midu.sh --sharpen 5     # Enfocar (1-10)
```

**Reverse** — Invertir vídeo (reproducción al revés):
```bash
./midu.sh --reverse
```

**Detectar escenas** — Cortar automáticamente en cambios de escena:
```bash
./midu.sh --scenes 0.3    # Umbral de detección (0.0-1.0)
```

**Extraer keyframes** — Sacar todas las imágenes I-frame:
```bash
./midu.sh --keyframes ./mis_keyframes
```

**Aspect ratio** — Cambiar ratio con letterboxing inteligente:
```bash
./midu.sh --aspect 16:9
./midu.sh --aspect 21:9    # Cine
./midu.sh --aspect 1:1     # Instagram
./midu.sh --aspect 9:16    # TikTok/Stories
```

**Metadata** — Editar información del vídeo:
```bash
./midu.sh --metadata title="Mi vídeo" artist="Yo" comment="Tutorial"
```

### Opciones avanzadas

**Two-pass encoding** — Mejor calidad al comprimir a tamaño fijo:
```bash
./midu.sh --convert --two-pass -g 2 -s telegram
```

**Aceleración por hardware** — Usar GPU para decodificar:
```bash
./midu.sh --convert --hw-accel -p web
```

**Dry-run** — Preview sin ejecutar:
```bash
./midu.sh --convert --dry-run -s telegram
```

**Checkpoint y resume** — Guardar progreso y continuar después:
```bash
./midu.sh --convert --checkpoint .progreso    # Guarda progreso
./midu.sh --convert --resume .progreso        # Continúa desde checkpoint
```

**Descarga de subtítulos** — Descargar subs automáticamente:
```bash
./midu.sh -d "URL" --write-subs --sub-langs "es,en"
```

**Notificación** — Aviso al terminar lote:
```bash
./midu.sh --convert --notify
```

## 4. Pasos para ejecutarlo en WSL

1. **Docker Desktop abierto** en Windows. En `Settings -> Resources -> WSL Integration`, activa tu distribución.

2. **Lanzar el contenedor:**

    ```sh
    docker compose run --remove-orphans --rm downloader
    ```

3. **Dentro del contenedor**, el menú interactivo se abre automáticamente. Solo selecciona el modo y sigue los pasos.

4. **Si prefieres CLI directamente:**

    ```sh
    bash midu.sh --convert -s telegram    # Convertir para Telegram
    bash midu.sh --cut -ss 5 -e 10        # Cortar de 5s a 10s
    bash midu.sh -d "URL"                  # Descargar vídeo
    bash midu.sh --info                    # Ver info del vídeo
    ```

5. **Al acabar**, escribe `exit` en la terminal del contenedor.

## 5. Ejecutar directamente en Ubuntu (sin Docker)

Instala las dependencias:

```sh
sudo apt update && sudo apt install ffmpeg
sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp && sudo chmod a+rx /usr/local/bin/yt-dlp
```

Hazlo ejecutable y ejecútalo:

```sh
chmod +x midu.sh
./midu.sh
```

```yaml
volumes:

```

Lanza el contenedor:

```sh
docker compose run --remove-orphans --rm downloader
```

## 7. Problemas que encontré y cómo los resolví

### Saltos de línea CRLF de Windows

**Errores:** `mkdi: command not found`, `syntax error near unexpected token 'do'`

**Causa:** El docker-compose.yml tenía saltos de línea Windows (CRLF).

**Solución:** Cambiar a LF en VS Code (clic en "CRLF" en la barra de estado).

### Archivos creados como root en los volúmenes

**Solución:** Usar `su-exec` para ejecutar como tu usuario real:

```yaml
adduser -D -u 1000 tu_usuario &&
su-exec tu_usuario bash midu.sh
```

### ffmpeg no encontraba subtítulos

**Causa:** El path de los subtítulos tenía caracteres especiales.

**Solución:** Escapar el path correctamente en el filtro de ffmpeg.

### pip mostraba warning de root

**Solución:** Redirigir output de pip:

```sh
pip install --break-system-packages yt-dlp 2>/dev/null; true
```
