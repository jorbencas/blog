## 1. El docker-compose.yml

Guarda los vídeos en tu disco de Windows <code>(C:)</code> para abrirlos con el reproductor de Windows. En WSL, tu disco <code>C:</code> está montado en <code>/mnt/c/</code>.

```yaml
services:
  downloader:
    image: alpine:latest
    container_name: yt_ffmpeg_downloader
    volumes:
      - /mnt/c/Users/TuUsuario/Videos/test_videos:/test_videos
    working_dir: /test_videos
    user: root
    tty: true
    stdin_open: true
    command: >-
      sh -c "apk update &&
      apk add --no-cache ffmpeg bash python3 py3-pip &&
      pip install --break-system-packages yt-dlp &&
      id -u jorge >/dev/null 2>&1 || adduser -D -u 1000 jorge &&
      chown -R jorge:jorge /test_videos &&
      su-exec jorge bash midu.sh"
```

> **Sobre `tty` e `stdin_open`:** Equivalen a `-it` en `docker run`. Sin ellas, no podrías escribir comandos dentro.

> **Sobre los permisos:** `user: root` para instalar paquetes, `su-exec` para ejecutar como tu usuario real. Cambia `jorge` por tu nombre de usuario (`whoami`).

> **Ojo:** Cambia `TuUsuario` por el nombre real de tu usuario en Windows (`ls /mnt/c/Users/`).

## 2. Estructura de carpetas

```
test_videos/
├── docker-compose.yml
├── midu.sh
├── conf.json           ← se crea automáticamente al guardar config
├── test/               ← meter aquí los vídeos
└── optimizados/        ← se crea automáticamente
```

## 3. Pasos para ejecutarlo en WSL

1. **Docker Desktop abierto** en Windows. En `Settings -> Resources -> WSL Integration`, activa tu distribución.

2. **Lanzar el contenedor:**

    ```sh
    docker compose run --remove-orphans --rm downloader
    ```

3. **Dentro del contenedor**, el menú interactivo se abre automáticamente. Solo selecciona el modo y sigue los pasos.

4. **Si prefieres CLI directamente:**

    ```sh
    bash midu.sh --convert -s telegram    # Convertir para Telegram
    bash midu.sh --cut -ss 5 -e 10        # Cortar de 5s a 10s
    bash midu.sh -d "URL"                  # Descargar vídeo
    bash midu.sh --info                    # Ver info del vídeo
    ```

5. **Al acabar**, escribe `exit` en la terminal del contenedor.

## 4. Ejecutar directamente en Ubuntu (sin Docker)

Instala las dependencias:

```sh
sudo apt update && sudo apt install ffmpeg
sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp && sudo chmod a+rx /usr/local/bin/yt-dlp
```

Hazlo ejecutable y ejecútalo:

```sh
chmod +x midu.sh
./midu.sh
```

## 5. Ejecutar con Docker en Ubuntu (sin WSL)

Ajusta las rutas en `docker-compose.yml`:

```yaml
volumes:
  - /home/TuUsuario/Videos/test_videos:/test_videos
```

Lanza el contenedor:

```sh
docker compose run --remove-orphans --rm downloader
```

## 6. Problemas que encontré y cómo los resolví

### Saltos de línea CRLF de Windows

**Errores:** `mkdi: command not found`, `syntax error near unexpected token 'do'`

**Causa:** El docker-compose.yml tenía saltos de línea Windows (CRLF).

**Solución:** Cambiar a LF en VS Code (clic en "CRLF" en la barra de estado).

### Archivos creados como root en los volúmenes

**Solución:** Usar `su-exec` para ejecutar como tu usuario real:

```yaml
adduser -D -u 1000 tu_usuario &&
su-exec tu_usuario bash midu.sh
```

### ffmpeg no encontraba subtítulos

**Causa:** El path de los subtítulos tenía caracteres especiales.

**Solución:** Escapar el path correctamente en el filtro de ffmpeg.

### pip mostraba warning de root

**Solución:** Redirigir output de pip:

```sh
pip install --break-system-packages yt-dlp 2>/dev/null; true
```
