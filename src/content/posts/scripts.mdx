Los tres scripts siguientes automatizan una tarea repetitiva: dado un conjunto de videoclases (`.mp4`) y sus pistas de audio grabadas por separado, detectar qué audio corresponde a cada video y fusionarlos en un único archivo con **ffmpeg**.

Conceptos comunes que se usan en los tres:

- [**Bucle `for`**](https://www.gnu.org/software/bash/manual/html_node/Looping-Constructs.html): itera sobre los archivos `.mp4` de una carpeta.
- [**Expansión de parámetros**](https://www.gnu.org/software/bash/manual/html_node/Shell-Parameter-Expansion.html): `"$variable"` para acceder al valor; `${variable}` para incrustarlo en cadenas.
- [**Sustitución de comandos**](https://www.gnu.org/software/bash/manual/html_node/Command-Substitution.html): `$(comando)` ejecuta un comando y devuelve su salida.
- [**`basename`**](https://www.gnu.org/software/coreutils/manual/html_node/basename-invocation.html): extrae el nombre del archivo sin ruta ni extensión.
- [**`realpath`**](https://www.gnu.org/software/coreutils/manual/html/node/realpath-invocation.html): resuelve la ruta absoluta de un archivo.
- [**`grep -oP`**](https://www.gnu.org/software/grep/manual/html_node/General-Output-Control.html): busca con Perl regex solo la parte que coincide (`-o`).
- [**`cut`**](https://www.gnu.org/software/coreutils/manual/html_node/cut-invocation.html): extrae columnas o caracteres de cada línea.
- [**`ffmpeg`**](https://ffmpeg.org/ffmpeg.html): herramienta de procesamiento audiovisual. Aquí se usa con `-c:v copy` (copia el video sin recodificar) y `-c:a aac` (codifica el audio a AAC).

## ar 1 — Psicobio 1 y 2

**Propósito**: Busca videos en `./VIDEOS`, localiza el audio correspondiente en dos subcarpetas posibles (`biolo1` o `biolo2`) y los fusiona.

**Flujo**:

1. Itera sobre cada `*.mp4` en `./VIDEOS`.
2. Extrae el número de tema (`T\d+`) del nombre del archivo con `grep -oP`.
3. Concatena ese número en las rutas de audio esperadas (`Psicobio 1 T{numero}-audio.mp4` en `biolo1`, y análoga en `biolo2`).
4. Comprueba qué archivo de audio existe realmente con `[ -f "$archivo" ]`.
5. Crea una carpeta de salida por video dentro de `./UNIDOS`.
6. Copia video y audio a la carpeta usando `realpath` (rutas absolutas).
7. Construye un comando ffmpeg como cadena y lo ejecuta con `eval`.
8. Si ffmpeg termina correctamente (código de salida `0`), mueve el resultado a `./UNIDOS` y limpia la carpeta temporal.

```bash
#!/bin/bash

videos_folder="./VIDEOS "
audios_folder="./Audios"
unidos_folder="./UNIDOS"

for video_file in "$videos_folder"/*.mp4; do
    t_number=$(echo "$video_file" | grep -oP 'T\d+' | cut -c2-)

    audio_file_1="$audios_folder/biolo1/Psicobio 1 T${t_number}-audio.mp4"
    audio_file_2="$audios_folder/biolo2/Psicobio 2 T${t_number}-audio.mp4"

    if [ -f "$video_file" ]; then
        if [ -f "$audio_file_1" ]; then
            audio_file="$audio_file_1"
        elif [ -f "$audio_file_2" ]; then
            audio_file="$audio_file_2"
        else
            echo "No se encontró el archivo de audio correspondiente para $video_file"
            continue
        fi
    else
        echo "No se encontró el archivo de video $video_file"
        continue
    fi

    mkdir -p "$unidos_folder"
    output_folder="$unidos_folder/$(basename "$video_file" .mp4)"
    mkdir -p "$output_folder"

    v_file="$output_folder/01.mp4"
    a_file="$output_folder/01-audio.mp4"
    if [ ! -f "$v_file" ] && [ ! -f "$a_file" ]; then
        cp "$(realpath "$video_file")" "$v_file"
        cp "$(realpath "$audio_file")" "$a_file"
        echo "CARPETA: $v_file"
        echo "Unión completa para $video_file"
    else
        echo "El archivo \"$v_file\" ya existe. No se hizo nada."
    fi

    if [ -f "$v_file" ] && [ -f "$a_file" ]; then
        output_folder_absolute=$(realpath "$output_folder")
        ar_videos_command="ffmpeg -i \"$output_folder_absolute/01.mp4\" -i \"$output_folder_absolute/01-audio.mp4\" -c:v copy -c:a aac -strict experimental \"$output_folder_absolute/001.mp4\""
        eval "$ar_videos_command"
        ffmpeg_exit_code=$?

        if [ $ffmpeg_exit_code -eq 0 ] && [ -f "$output_folder/001.mp4" ]; then
            mv "$output_folder/001.mp4" "$output_folder/$(basename "$output_folder").mp4"
            echo "Conversión completa para la carpeta $(basename "$output_folder")"
            mv "$output_folder/$(basename "$output_folder").mp4" "$unidos_folder"
            rm -r "$output_folder"
            echo "Movido y borrado correctamente."
        else
            echo "Error: No se generó el archivo de salida correctamente."
        fi
    else
        echo "No se encontraron archivos de video y audio en la carpeta $output_folder"
    fi
done
```

## ar 3 — Social (un solo origen)

**Propósito**: Misma operación pero más simple. Los videos y audios están en la misma carpeta (`./VIDEOCLASES SOCIAL`), el nombre del audio sigue el patrón `Social T{numero}-audio.mp4` y solo hay un subdirectorio que comprobar.

La lógica es más limpia porque elimina la doble búsqueda de ar 1/ar 2.

```sh
#!/bin/bash

source_folder="./VIDEOCLASES SOCIAL"
unidos_folder="./UNIDOS"

for video_file in "$source_folder"/*.mp4; do
    t_number=$(echo "$video_file" | grep -oP 'T\d+' | cut -c2-)
    audio_file="$source_folder/Social T${t_number}-audio.mp4"

    if [ -f "$video_file" ]; then
        if [ -f "$audio_file" ]; then
            mkdir -p "$unidos_folder"
            output_folder="$unidos_folder/$(basename "$video_file" .mp4)"
            mkdir -p "$output_folder"

            if [ ! -f "$output_folder/01.mp4" ]; then

                echo "Unión completa para $video_file"
```

## Cómo mejorar estos scripts

### Seguridad y robustez

1. **`set -euo pipefail`** — al inicio del script detiene la ejecución si un comando falla (`-e`), si usas variables no definidas (`-u`) o si un pipe falla (`-o pipefail`). Referencia: [The Set Builtin](https://www.gnu.org/software/bash/manual/html_node/The-Set-Builtin.html).

2. **Evitar `eval`** — `eval` ejecuta una cadena como si fuera código. Si algún nombre de archivo contiene caracteres especiales (`;`, `` ` ``, `$`, etc.), puede ejecutar comandos no deseados. Mejor usar un array:

   ```bash
   ffmpeg_args=(
       -i "$output_folder_absolute/01.mp4"
       -i "$output_folder_absolute/01-audio.mp4"
       -c:v copy -c:a aac -strict experimental
       "$output_folder_absolute/001.mp4"
   )
   ffmpeg "${ffmpeg_args[@]}"
   ```

3. **[`[[ ]]` en lugar de `[ ]`](https://www.gnu.org/software/bash/manual/html_node/Conditional-Constructs.html)** — `[[ ]]` es más seguro (no parte palabras) y soporta operadores como `=~` (regex) sin necesidad de escapar.

4. **Comillas siempre** — `"$variable"` evita que el shell divida el valor por espacios o expanda comodines. Varios lugares en los scripts originales tienen variables sin comillas.

5. **`trap` para limpiar en errores** — si el script falla a mitad, las carpetas temporales quedan huérfanas. Con `trap "rm -rf $output_folder" ERR` se limpian automáticamente.

### Mejoras funcionales

6. **Extraer metadatos con `ffprobe`** en lugar de `grep` + `cut` — si el número de tema está en los metadatos del video, `ffprobe` es más fiable que parsear el nombre del archivo:

   ```bash
   t_number=$(ffprobe -v error -show_entries format_tags=title -of default=noprint_wrappers=1:nokey=1 "$video_file")
   ```

7. **Refactorizar en funciones** — la lógica de buscar audio, copiar y ejecutar ffmpeg se repite idéntica en los tres scripts. Una función `merge_video_audio` eliminaría la duplicación:

   ```bash
   merge_video_audio() {
       local video="$1" audio="$2" output_dir="$3"
       # ... lógica común ...
   }
   ```

8. **[`parallel`](https://www.gnu.org/software/parallel/) para procesar en paralelo** — si hay muchos videos, ffmpeg solo usa un núcleo por instancia. Con GNU parallel se lanzan varios procesos simultáneos:

   ```bash
   ls *.mp4 | parallel -j4 merge_video_audio {} {}.audio.mp3 ./UNIDOS
   ```

9. **Nombres de salida más descriptivos** — en lugar de `001.mp4`, usar el nombre original del video o un patrón como `{nombre}_{calidad}.mp4`.

10. **Logging** — redirigir la salida de ffmpeg a un archivo de log por si algo falla: `ffmpeg ... &>> ffmpeg.log`.

### Resumen de cambios prioritarios

| Problema | Riesgo | Solución |
|---|---|---|
| Sin `set -e` | El script continúa tras un error | Añadir `set -euo pipefail` |
| `eval` en comandos ffmpeg | Inyección de comandos | Usar arrays |
| Variables sin comillas | División por espacios | `"$variable"` siempre |
| Sin `trap` | Carpetas temporales huérfanas | `trap cleanup EXIT ERR` |
| Código duplicado x3 | Mantenimiento difícil | Refactorizar a funciones |
