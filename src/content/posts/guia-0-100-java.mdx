# Guía de Java: De 0 a 100

## 🛠️ Requisitos e Instalación

**Todas las plataformas:** Descarga **Eclipse Temurin JDK 21 LTS** desde [adoptium.net](https://adoptium.net/). O desde [oracle.com](https://www.oracle.com/java/).
**Linux (apt):** `sudo apt install openjdk-21-jdk` — instala OpenJDK desde repos oficiales.
**Post-instalación:** Configura `JAVA_HOME` apuntando al directorio del JDK y añade `$JAVA_HOME/bin` al PATH.
**Verificación:** `--version` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **Maven** (`mvn`) o **Gradle** para build y dependencias. IntelliJ IDEA (Community gratis) es el IDE más usado.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Clases y Métodos:** `public class Main { public static void main(String[] args) { ... } }`. PascalCase para clases, camelCase para métodos. El método `main` es el punto de entrada.
- **Tipos de Datos:** Primitivos: `int`, `long`, `double`, `float`, `boolean`, `char`. Wrappers: `Integer`, `Double` con auto-boxing/unboxing desde Java 5.
- **Control de Flujo:** `if-else`, `switch` (arrow syntax desde Java 14), `for` (clásico y enhanced), `while`. `switch` como expresión: `int d = switch(dia) { case "LUN" -> 1; ... };`
- **POO:** Herencia con `extends`. Interfaces con `implements` (métodos default desde Java 8). Encapsulación con `private`/`public`/`protected`. Polimorfismo con overriding y overloading.
- **Streams y Lambdas:** `list.stream().filter(x -> x > 5).map(String::valueOf).collect(Collectors.toList())`. `Optional<T>` evita NullPointerException. Programación funcional desde Java 8.

## 🏗️ Frameworks Populares

### Spring Boot
**Instalación:** `Usa [start.spring.io](https://start.spring.io/) o curl para generar el proyecto base.`
Framework dominante en Java. Auto-configuración, DI, seguridad (Spring Security), datos (Spring Data JPA) y microservicios (Spring Cloud).
```java
@RestController
@RequestMapping("/api")
public class SaludoController {
    @GetMapping("/saludo")
    public String saludo() {
        return "Hola Mundo";
    }
}
```

## 📝 Ejercicios Prácticos

1. **POO Básica** 🟢 `[Fácil]` — Clase abstracta `Animal` con `hacerSonido()`. Extiende con `Perro` y `Gato`. Demuestra polimorfismo.
2. **Streams API** 🟡 `[Intermedio]` — Dada una lista de empleados (nombre, departamento, salario), obtén el salario medio por departamento.
3. **REST API con Spring Boot** 🟡 `[Intermedio]` — CRUD de tareas con endpoints GET, POST, PUT, DELETE. Almacena en memoria.
4. **Concurrencia** 🔴 `[Avanzado]` — Productor-consumidor con `ExecutorService`, `BlockingQueue` y `Callable<V>`. Mide throughput.

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Sigue convenciones Java: PascalCase para clases, camelCase para métodos, MAYUSCULAS para constantes.
- Usa `Optional` para valores que pueden ser nulos.
- Prefiere composición sobre herencia.
- Usa `record` (Java 14+) para datos inmutables.
- Usa try-with-resources para recursos autocerrables.
- Escribe tests con JUnit 5 y Mockito.

**Complejidad algorítmica (Big O):**

ArrayList: acceso O(1), inserción/eliminación O(n). HashMap: O(1) promedio. TreeMap: O(log n). `Collections.sort()` (TimSort) O(n log n).
