# Guía de Java: De 0 a 100

Java es un lenguaje orientado a objetos, robusto y con un ecosistema gigante.

## 🛠️ Requisitos e Instalación

1. Instalar JDK (OpenJDK recomendado).
2. Configurar JAVA_HOME.
3. Probar con `java -version`.

## 🚀 Hola Mundo y Sintaxis Básica

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hola Mundo");
    }
}
```

Todo ocurre dentro de clases. Tipado estático y verboso.

## 📝 Ejercicios Prácticos

1. **POO**: Crea una clase Animal y una subclase Perro.
2. **Streams API**: Filtra y mapea una lista de números usando Streams.
3. **REST Controller**: Define un @RestController simple en Spring Boot.
