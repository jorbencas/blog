# Guía de Python: De 0 a 100

## 🛠️ Requisitos e Instalación

**Windows:** Descarga el instalador desde [python.org](https://python.org). **Marca "Add Python to PATH"** durante la instalación.
**macOS:** Usa Homebrew: `brew install python3`. Verifica con `python3 --version`.
**Linux:** `sudo apt update && sudo apt install python3 python3-pip python3-venv` (Debian/Ubuntu) o `sudo dnf install python3` (Fedora).
**Verificación:** `--version` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **pip** para paquetes, **venv** para entornos virtuales. IDE: VSCode + extensión Python, o PyCharm.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Variables y Tipos:** Tipado dinámico: `nombre = "Ana"`, `edad = 30`. Tipos: `int`, `float`, `str`, `bool`, `list`, `dict`. Usa `type()` para inspeccionar.
- **Condicionales y Bucles:** `if edad >= 18: ...` sin paréntesis obligatorios. `for x in iterable:` para recorrer. `while cond:` para bucles condicionales. `range(n)` genera secuencias.
- **Funciones:** `def suma(a, b): return a + b`. Parámetros por defecto, `*args`/`**kwargs`. Type hints opcionales desde PEP 484. Puede devolver múltiples valores.
- **Estructuras de Datos:** Listas mutables con `append()`, `pop()`, slicing. Diccionarios `{clave: valor}` con acceso O(1). Tuplas inmutables. Sets `{1, 2, 3}` sin duplicados.
- **POO:** `class Nombre:` con `__init__` como constructor. `self` es explícito. Herencia: `class Hijo(Padre)`. Métodos mágicos: `__str__`, `__len__`, `__eq__`.

## 🏗️ Frameworks Populares

### FastAPI
**Instalación:** `pip install fastapi uvicorn`
Framework moderno con validación automática basada en type hints. Soporta async, OpenAPI automático y docs interactivos en `/docs`.
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def raiz():
    return {"mensaje": "Hola Mundo"}
```
### Django
**Instalación:** `pip install django`
Framework full-stack con ORM, admin panel, autenticación y más. Sigue MTV (Model-Template-View). Ideal para apps completas con base de datos.
```python
# django-admin startproject mysite
# python manage.py runserver
from django.http import HttpResponse

def home(request):
    return HttpResponse("Hola Mundo")
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Sigue PEP 8 — usa `ruff` o `black` para formateo automático.
- Usa `is` para comparar con `None`, no `==`.
- Prefiere `pathlib.Path` sobre `os.path`.
- Usa `with` para manejar recursos (archivos, conexiones).
- Escribe type hints — permiten verificación estática con `mypy`.
- Usa comprensiones de listas y generadores para código conciso.

**Complejidad algorítmica (Big O):**

Listas: acceso O(1), búsqueda O(n), inserción O(n). Diccionarios: O(1) promedio para inserciones y búsquedas. `sorted()` es O(n log n).
