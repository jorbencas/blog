# Guía de Python: De 0 a 100

Python es un lenguaje versátil, fácil de leer y potente, ideal para ciencia de datos y web.

## 🛠️ Requisitos e Instalación

1. Descarga desde python.org.
2. Instala usando el instalador oficial.
3. Verifica con `python --version`.

## 🚀 Hola Mundo y Sintaxis Básica

```python
print("Hola Mundo")
```

Usa indentación para bloques. Tipado dinámico pero fuerte.

## 🏗️ Frameworks Populares

### FastAPI

**Instalación:**
```bash
pip install fastapi uvicorn
```

**Estructura Principal:**
Usa decoradores para rutas. Soporta tipado de Python para validación automática.

## 📝 Ejercicios Prácticos

1. **Calculadora**: Crea una función que sume dos números.
2. **Web API**: Un endpoint simple con FastAPI que retorne un JSON.
3. **Scraper**: Usa requests para obtener el HTML de una web.
