# Guía de TypeScript: De 0 a 100

TypeScript añade tipado estático a JavaScript, permitiendo detectar errores antes de ejecutar el código.

## 🛠️ Requisitos e Instalación

1. Instalar Node.js.
2. Ejecutar `npm install -g typescript`.
3. Compilar con `tsc`.

## 🚀 Hola Mundo y Sintaxis Básica

```typescript
let msg: string = "Hola Mundo"; console.log(msg);
```

Define tipos con interfaces y tipos. Soporta clases modernas.

## 🏗️ Frameworks Populares

### NestJS

**Instalación:**
```bash
npm i -g @nestjs/cli && nest new project-name
```

**Estructura Principal:**
Arquitectura modular inspirada en Angular (Módulos, Controladores, Servicios).

## 📝 Ejercicios Prácticos

1. **Interface**: Crea una interfaz de Usuario y una función que la use.
2. **Generic**: Implementa una función genérica de identidad.
3. **Decorator**: Usa un decorador simple para loguear llamadas a clases.
