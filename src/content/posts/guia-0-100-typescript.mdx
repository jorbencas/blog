# Guía de TypeScript: De 0 a 100

## 🛠️ Requisitos e Instalación

**Global:** `npm install -g typescript` — instala el compilador `tsc` globalmente.
**Proyecto:** `npm init -y && npm install --save-dev typescript @types/node && npx tsc --init`
**Online:** [TypeScript Playground](https://www.typescriptlang.org/play/) para probar sin instalar.
**Verificación:** `npm install -g typescript` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **tsconfig.json** controla la compilación. Opciones clave: `strict: true`, `target: ES2022`. VSCode tiene soporte nativo excelente.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Tipos Básicos:** `: string`, `: number`, `: boolean`. Arrays: `number[]` o `Array<number>`. Tuplas: `[string, number]`. `any` desactiva el chequeo (evítalo). `unknown` es seguro.
- **Interfaces y Types:** `interface Usuario { nombre: string; edad?: number; }`. `type Id = string | number`. Prefiere `interface` para objetos extensibles, `type` para uniones.
- **Funciones Tipadas:** `function suma(a: number, b: number): number { return a + b; }`. Parámetros opcionales con `?`. Sobrecarga con múltiples firmas.
- **Genéricos:** `function identidad<T>(arg: T): T { return arg; }`. Restricciones: `<T extends Lengthwise>`. Permite código reusable tipo-seguro.
- **Enums y Union Types:** `enum Color { Rojo, Verde, Azul }`. Union: `type Estado = "activo" | "inactivo"`. Discriminated unions para pattern matching con switch.

## 🏗️ Frameworks Populares

### NestJS
**Instalación:** `npm i -g @nestjs/cli && nest new mi-app`
Framework backend progresivo con arquitectura modular. Decoradores, DI, MVC. Soporta GraphQL, WebSockets y microservicios.
```typescript
import { Module, Controller, Get } from '@nestjs/common';

@Controller('saludo')
export class SaludoController {
  @Get()
  getSaludo(): { mensaje: string } {
    return { mensaje: 'Hola Mundo' };
  }
}
```
### Next.js
**Instalación:** `npx create-next-app@latest mi-app`
Framework React full-stack. SSR, SSG, ISR. App Router (sistema de archivos), Server Components, API routes integradas.
```typescript
export default function Home() {
  return <h1>Hola Mundo</h1>;
}

export async function getServerSideProps() {
  return { props: { data: 'desde el servidor' } };
}
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Activa `strict: true` en tsconfig.json desde el inicio.
- Usa `unknown` en lugar de `any` — fuerza verificación antes de usar.
- Define interfaces en archivos separados y expórtalas.
- Usa `as const` para literales y `satisfies` para verificación sin ensanchar tipo.
- No abuses de `as` (type assertion) — si lo usas mucho, el diseño de tipos puede estar mal.
- Configura `noUnusedLocals` y `noUnusedParameters` para código limpio.

**Complejidad algorítmica (Big O):**

Al compilar a JS, la complejidad es la del JS generado. TypeScript no añade overhead runtime. El análisis de tipos ocurre en compilación (O(n) respecto al tamaño del código).
