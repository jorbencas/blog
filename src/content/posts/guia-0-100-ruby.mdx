# Guía de Ruby: De 0 a 100

Ruby es un lenguaje dinámico y de código abierto enfocado en la simplicidad y la productividad.

## 🛠️ Requisitos e Instalación

1. Usar rbenv o rvm para instalar Ruby.
2. `ruby -v`.

## 🚀 Hola Mundo y Sintaxis Básica

```ruby
puts "Hola Mundo"
```

Todo es un objeto. Bloques, procs y lambdas son muy comunes.

## 🏗️ Frameworks Populares

### Ruby on Rails

**Instalación:**
```bash
gem install rails
```

**Estructura Principal:**
Filosofía 'Convención sobre Configuración' (CoC) y DRY.

## 📝 Ejercicios Prácticos

1. **Iterador**: Usa `.each` para recorrer una lista de nombres.
2. **Clase Persona**: Crea una clase con atributos y un método de saludo.
3. **Scaffold**: Genera un CRUD completo en Rails con un solo comando.
