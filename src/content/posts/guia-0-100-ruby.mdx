# Guía de Ruby: De 0 a 100

## 🛠️ Requisitos e Instalación

**Linux/macOS:** Usa **rbenv**: `git clone https://github.com/rbenv/rbenv.git ~/.rbenv && ~/.rbenv/bin/rbenv init`. O **RVM**: `curl -sSL https://get.rvm.io | bash`.
**Windows:** [RubyInstaller](https://rubyinstaller.org/) — incluye Ruby, gems, y MSYS2.
**Directo (Linux):** `sudo apt install ruby-full` — pero version manager es preferible.
**Verificación:** `git clone https://github.com/rbenv/rbenv.git ~/.rbenv && ~/.rbenv/bin/rbenv init` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **Bundler** (`gem install bundler`) para dependencias. **RSpec** para tests. **rubocop** para linting. **pry** para debugging interactivo.

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Todo es Objeto:** `42.class` → Integer. `"hola".class` → String. No hay primitivos. `nil` es un objeto (NilClass).
- **Métodos y Bloques:** `def saludar(nombre) "Hola, #{nombre}" end`. Bloques: `[1,2,3].each { |n| puts n }`. `yield` invoca un bloque desde un método.
- **Símbolos y Strings:** Símbolos `:nombre` — inmutables, únicos, ideales para keys. Strings mutables. Interpolación: `"Hola #{nombre}"`.
- **POO Dinámico:** Módulos como mixins (`include`, `extend`). `attr_accessor :nombre`. Duck typing. `method_missing` para delegación dinámica.
- **Enumerable:** `.map`, `.select`, `.reduce`, `.any?`, `.all?`, `.group_by`. Rangos `(1..10)`. Blocks + enumerables = máximo poder expresivo.

## 🏗️ Frameworks Populares

### Ruby on Rails
**Instalación:** `gem install rails && rails new mi_app`
Framework full-stack que popularizó CoC. ActiveRecord ORM, Action Cable (WebSockets), Active Storage, testing integrado. Ideal para prototipado rápido.
```ruby
# config/routes.rb
Rails.application.routes.draw do
  root 'home#index'
  get '/saludo/:nombre', to: 'home#saludo'
end

# app/controllers/home_controller.rb
class HomeController < ApplicationController
  def index
    render plain: 'Hola Mundo'
  end
  def saludo
    render json: { mensaje: "Hola, #{params[:nombre]}" }
  end
end
```
### Sinatra
**Instalación:** `gem install sinatra`
Microframework web minimalista. DSL elegante, perfecto para APIs pequeñas y prototipos.
```ruby
require 'sinatra'

get '/' do
  'Hola Mundo'
end

get '/saludo/:nombre' do
  content_type :json
  { mensaje: "Hola, #{params[:nombre]}" }.to_json
end
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Sigue Ruby Style Guide. Usa RuboCop para verificación automática.
- Prefiere bloques de una línea con `{}` y multínea con `do..end`.
- Usa `symbol` en lugar de `string` para identificadores y keys de hash.
- Escribe tests con RSpec — describe context it expect.
- Usa `||=` para memoización: `@cache ||= compute_heavy`.

**Complejidad algorítmica (Big O):**

Arrays: acceso O(1), búsqueda O(n), push/pop O(1). Hashes: O(1) promedio. Enumerable#sort: O(n log n). Range#include?: O(1) para rangos numéricos.
