# Guía de Go (Golang): De 0 a 100

## 🛠️ Requisitos e Instalación

**Linux/macOS:** `wget https://go.dev/dl/go1.22.x.linux-amd64.tar.gz && sudo tar -C /usr/local -xzf go1.22.x.tar.gz`. Añade `/usr/local/go/bin` al PATH.
**Windows:** Usa el instalador MSI desde [go.dev/dl](https://go.dev/dl/). Se añade automáticamente al PATH. O: `winget install GoLang.Go`.
**Verificación:** `wget https://go.dev/dl/go1.22.x.linux-amd64.tar.gz && sudo tar -C /usr/local -xzf go1.22.x.tar.gz` y prueba con un `"Hola Mundo"`.
**Herramientas recomendadas:** **`go mod init`** para módulos. **`go get`** para dependencias. **`go build`** compila binarios estáticos. VSCode + extensión Go (gopls).

## 🚀 Hola Mundo y Sintaxis Básica

**Conceptos clave:**

- **Paquetes y Main:** `package main` para ejecutables. `func main()` es el punto de entrada. `import "fmt"` para I/O. Variables no usadas = error de compilación.
- **Variables y Tipos:** `var nombre string = "Ana"` o inferencia `:=`. Tipos: `string`, `int`, `float64`, `bool`, `byte`, `rune`. Zero values por defecto.
- **Control de Flujo:** `if`, `else`, `for` (único bucle — no hay while). `switch` sin break automático. `defer` aplaza ejecución al salir de la función.
- **Structs e Interfaces:** `type Usuario struct { Nombre string; Edad int }`. Métodos: `func (u Usuario) Saludar() string`. Interfaces implícitas: si implementas los métodos, implementas la interfaz.
- **Concurrencia:** `go funcion()` lanza goroutines (hilos ligeros). `ch := make(chan int)` para canales. `select` espera múltiples canales. `sync.WaitGroup` para sincronización.

## 🏗️ Frameworks Populares

### Gin Gonic
**Instalación:** `go get -u github.com/gin-gonic/gin`
Framework web minimalista con enrutamiento basado en árbol radix. Middleware integrado, validación y serialización JSON.
```go
package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()
    r.GET("/", func(c *gin.Context) {
        c.JSON(200, gin.H{"mensaje": "Hola Mundo"})
    })
    r.Run()
}
```
### stdlib net/http
**Instalación:** `No necesita instalación — incluido en Go.`
La stdlib incluye servidor HTTP completo, cliente HTTP, templates, JSON/XML, tests, y más. Muchos proyectos no necesitan frameworks externos.
```go
package main

import (
    "fmt"
    "net/http"
)

func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hola Mundo")
}

func main() {
    http.HandleFunc("/", handler)
    http.ListenAndServe(":8080", nil)
}
```

## ⚡ Buenas Prácticas y Complejidad

**Buenas prácticas:**

- Ejecuta `go fmt` en todos los archivos — el formateo es parte del lenguaje.
- Usa `go mod tidy` para limpiar dependencias no usadas.
- Nombra los valores de retorno: `func div(a, b int) (result int, err error)`.
- Prefiere `error` sobre panic/recover.
- Usa `context.Context` para timeouts y cancelaciones entre goroutines.
- Escribe tests con `testing` y benchmarks con `go test -bench`.

**Complejidad algorítmica (Big O):**

Slices: acceso O(1), append O(1) amortizado, búsqueda O(n). Maps: O(1) promedio. Canales: envío/recepción O(1). `sort.Slice()` O(n log n).
