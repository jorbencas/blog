# Guía de Go (Golang): De 0 a 100

Go es un lenguaje compilado enfocado en la simplicidad, la eficiencia y el manejo de concurrencia mediante goroutines.

## 🛠️ Requisitos e Instalación

1. Descarga desde go.dev.
2. Configura el GOPATH.
3. Verifica con `go version`.

## 🚀 Hola Mundo y Sintaxis Básica

```go
package main
import "fmt"

func main() {
    fmt.Println("Hola Mundo")
}
```

Sin clases, usa structs e interfaces. Manejo de paquetes explícito.

## 🏗️ Frameworks Populares

### Gin Gonic

**Instalación:**
```bash
go get -u github.com/gin-gonic/gin
```

**Estructura Principal:**
Enfoque en middleware y rutas ultra-rápidas mediante un árbol de búsqueda.

## 📝 Ejercicios Prácticos

1. **Goroutines**: Ejecuta un bucle en paralelo usando la palabra clave `go`.
2. **JSON API**: Crea un servidor HTTP que responda un JSON usando Gin.
3. **Channels**: Comunica dos goroutines usando un canal.
