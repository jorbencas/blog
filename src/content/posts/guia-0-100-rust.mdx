# Guía de Rust: De 0 a 100

Rust garantiza seguridad de memoria mediante su sistema de propiedad (ownership) y préstamo (borrowing).

## 🛠️ Requisitos e Instalación

1. Usar rustup: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`.

## 🚀 Hola Mundo y Sintaxis Básica

```rust
fn main() {
    println!("Hola Mundo");
}
```

Fuertemente tipado. Usa `match` para control de flujo exhaustivo.

## 🏗️ Frameworks Populares

### Actix-Web

**Instalación:**
```bash
cargo add actix-web
```

**Estructura Principal:**
Basado en actores y procesamiento asíncrono eficiente.

## 📝 Ejercicios Prácticos

1. **Ownership**: Experimenta moviendo una variable de un scope a otro.
2. **Error Handling**: Usa Result e Option para manejar un caso de error.
3. **Calculadora CLI**: Lee de la entrada estándar y realiza operaciones básicas.
