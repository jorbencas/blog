Tengo un montón de PDFs: certificados, títulos académicos, contratos, informes. Algunos están protegidos con contraseña, otros tienen restricciones de "solo lectura" que no me dejan editar, y cuando necesito unir varios en uno solo, la mayoría de herramientas online son lentas, ponen marcas de agua o limitan el tamaño.

**Mi motivación:** Un día necesitaba enviar un certificado que tenía en PDF pero estaba protegido. No podía editarlo, no podía unirlo con otros documentos, y las herramientas online me pedían que subiera mis documentos a sus servidores (con datos personales, eso no). Quería algo local, rápido y sin restricciones.

Así que hice **PDF Ninja Master**: una herramienta que gestiona todo tipo de operaciones con PDFs desde la terminal, con un sistema de doble intento para desbloquear cualquier tipo de protección.

---

## El problema

Los PDFs protegidos con restricciones de "solo lectura" o contraseñas de apertura son un obstáculo común. Las herramientas online tienen limitaciones de tamaño, ponen marcas de agua o envían tus documentos a servidores externos. Las de escritorio suelen ser de pago o no manejan bien las restricciones de propiedad.

## La solución

Una herramienta de línea de comandos en Python que gestiona PDFs protegidos con un sistema de doble intento: primero intenta la vía rápida (`pikepdf`) y si falla, activa la vía profunda (`PyMuPDF`). Todo con una interfaz de terminal con colores, paneles y progreso en tiempo real.

---

## Sistema de doble intento

El corazón del desbloqueo es el método `ejecutar_mision()` que usa dos bibliotecas complementarias:

### Intento 1: pikepdf (rápido)

```python
with pikepdf.open(r_in, password=password) as pdf:
    pdf.save(r_out)
```

`pikepdf` se basa en QPDF y es excelente para eliminar restricciones de propiedad (como "solo lectura" impuesto por el creador). No necesita contraseña de apertura si el PDF solo tiene restricciones de edición.

### Intento 2: PyMuPDF (profundo)

```python
doc = fitz.open(r_out)
doc.save(r_out, garbage=4 if comprimir else 3, deflate=comprimir, incremental=False)
doc.close()
```

Si `pikepdf` falla (por ejemplo, si el PDF tiene contraseñas de apertura o restricciones más complejas), `PyMuPDF` (fitz) toma el relevo. También se usa para la compresión:

- `garbage=4`: Elimina objetos no referenciados (máxima limpieza)
- `deflate=True`: Comprime streams de datos
- `incremental=False`: Guarda el archivo completo, no incremental

### Contraseñas de apertura

Si el PDF tiene contraseña de apertura, el script la pide al usuario:

```python
except pikepdf.PasswordError:
    password = Prompt.ask("Introduce la contraseña para este PDF")
    if not password:
        # Saltar archivo
```

## Unión interactiva: interfaz TUI

El modo de unión usa una interfaz de terminal completa con `rich.live` y `readchar` para navegación en tiempo real:

```

│  PDF NINJA (Filtro: )                                    │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ 🥷 MANDOS                                           │ │
│ │  MODO:   SELECCIÓN                                  │ │

│ ├────────────────────────────┬────────────────────────┤ │
│ │ 📂 DISPONIBLES             │ 🛒 COLA                │ │
│ │  certificado.pdf           │  titulo.pdf            │ │
```

### Controles

| Tecla | Acción |
|-------|--------|
| `↑` / `↓` | Navegar por la lista |
| `ENTER` | Añadir archivo a la cola |
| `TAB` | Alternar entre disponibles y cola |
| `CTRL+X` | Eliminar de la cola |
| `CTRL+S` | Unir archivos en la cola |
| `ESC` | Cancelar |
| Filtro | Escribe para filtrar por nombre |

La unión usa `fitz.open()` y `doc_u.insert_pdf()` para combinar los PDFs, luego guarda con `garbage=4` y `deflate=True` para máxima compresión.

## Conversión de imágenes

Convierte JPG, PNG o WebP en un único PDF:

```python
for foto in tqdm(fotos, desc="Procesando imágenes"):
    img = Image.open(os.path.join(self.entrada, foto)).convert("RGB")
    lista_imgs.append(img)

primera = lista_imgs.pop(0)
primera.save(nombre_out, save_all=True, append_images=lista_imgs)
```

## División por páginas

Extrae rangos específicos de un PDF:

```python
with fitz.open(archivo_sel) as doc:
    desde = IntPrompt.ask("Desde página", default=1)
    hasta = IntPrompt.ask("Hasta página", default=doc.page_count)
    nuevo = fitz.open()
    nuevo.insert_pdf(doc, from_page=desde-1, to_page=hasta-1)
    nuevo.save(f"split_{archivo_sel}")
```

## Uso con Docker

```bash
cd pdfmanager
docker compose build
docker compose up
```

Los PDFs se procesan desde `./pdfs_protegidos/` y salen en `./pdfs_libres/`.

## Uso sin Docker

```bash
cd pdfmanager
python3 -m venv .venv
source .venv/bin/activate
python desproteger_pdf.py
```

## Peculiaridades

- **Salto inteligente**: Detecta archivos ya procesados para evitar duplicar trabajo
- **Auto-setup**: Instala dependencias automáticamente si faltan
- **Colores consistentes**: Paleta azul/verde (`BG = "blue"`, `FG = "green"`) en toda la interfaz
- **Compresión máxima**: `garbage=4` + `deflate=True` para reducir tamaño sin romper validez
- **Manejo de errores**: Si un archivo falla, lo salta y continúa con el siguiente
