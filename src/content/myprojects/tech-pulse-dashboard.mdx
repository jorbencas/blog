## 1. El Planteamiento del Problema

El ecosistema tecnológico publica decenas de noticias, vídeos y recursos cada día. Seguir el ritmo manualmente es imposible. Herramientas como Feedly o Google News son genéricas, no filtran por relevancia técnica real ni ofrecen resúmenes inteligentes.

Se necesitaba un sistema que:
- Recolectara automáticamente contenido de 139 fuentes (YouTube, blogs tech, RSS, redes sociales)
- Clasificara y deduplicara el contenido en tiempo real
- Generara resúmenes por noticia y un recap semanal con IA
- Desplegara un dashboard interactivo con filtros combinables
- Enviara notificaciones por Telegram cada 30 minutos con audio TTS
- Enviara una newsletter diaria con resúmenes curados

## 2. La Solución Arquitectónica

**Tech Pulse** nace como un pipeline completo de automatización orquestado por GitHub Actions, construido en Python asíncrono con scripts modulares independientes.

### Capas del Sistema

- **Capa de Extracción (Scraping):** Arquitectura de extractores especializados:
  - `YouTubeExtractor` — parsea JSON `ytInitialData` directamente (vídeos, shorts, livestreams)
  - `WebExtractor` — BeautifulSoup con selectores CSS personalizados por fuente + `extraer_rss()` para feeds XML (RSS 2.0 y Atom)
  - `ScraperPro` facade con semáforo de concurrencia (5 peticiones simultáneas)
  - `AvatarRepository` — caché de avatares de canales YouTube con fallback a UI Avatars

- **Capa de Procesamiento IA:** Integración con Gemini API para:
  - Resumen semanal con análisis de tendencias (modelo `gemini-2.5-pro`)
  - Resumen individual por noticia (vía `extraer_texto_articulo()` + `resumir_noticia()`)
  - Traducción de títulos al español en lote
  - Generación de imágenes para posts con Imagen

- **Capa de Persistencia:** Historial JSON con deduplicación automática por URL normalizada y título similar, truncado a 900 entradas.

- **Capa de Distribución:**
  - Dashboard HTML/JS estático desplegado en Surge.sh
  - Newsletter HTML con diseño responsive vía Mailgun
  - Notificaciones Telegram cada 30 min con audio edge-tts (voz española)
  - Posts en markdown para blog Astro vía PR automático

### Pipeline de Contenido

Cada script es independiente y orquestable por separado:

1. `scrape_news.py` → `files/noticias_historico.json` (web + YouTube + RSS)
2. `scrape_tools.py` → `files/herramientas.json` (GitHub Trending + Product Hunt)
3. `scrape_trends.py` → `files/trends.json` (Google Trends + TikTok via Playwright)
4. `generate_weekly.py` → `auto-news/` (recap MD) + `public/` (dashboard + data.json)
5. `send_email.py` → Mailgun (diario 09:00 UTC)
6. `send_telegram.py` → Telegram con TTS (cada 30 min)

## 3. Retos Técnicos y Decisiones de Diseño

### Arquitectura Modular vs Monolito

Originalmente todo el scraping vivía en un único `downloadFile.py`. Se refactorizó a 6 scripts independientes para permitir ejecución selectiva por workflow y facilitar el mantenimiento. Cada script tiene sus propias dependencias y puede ejecutarse en solitario.

### Deduplicación Inteligente

La función `deduplicar_items()` en `utils.py` elimina duplicados en dos niveles:
- **URL normalizada:** quita `?utm_*`, `#fragment`, trailing `/`, normaliza `http` → `https`
- **Título similar:** compara el prefijo al 85% del título más corto para detectar la misma noticia con variaciones

```python
def normalizar_url(url: str) -> str:
    url = url.split("?")[0].split("#")[0].rstrip("/")
    return url.replace("http://", "https://").lower()
```

### 20 Fuentes RSS

Se añadieron fuentes RSS como alternativa ligera a scraping HTML: OpenAI Blog, Anthropic Blog, Google DeepMind, Meta AI Blog, Mistral AI News, Hacker News, Stack Overflow Blog, LangChain Blog, Google AI Blog, MIT Tech Review AI, Google Search Central, Moz Blog SEO, Search Engine Journal, Wired AI, The Verge AI, TechCrunch AI, Ars Technica AI, Dev.to, GitHub Engineering. El parser soporta RSS 2.0 y Atom, con detección automática de namespace.

### Renderizado Client-Side del Dashboard

Python genera un `index.html` shell (~2KB) + `data.json` con el historial completo. JavaScript (`script.js`) construye dinámicamente:

- **Filtros combinables:** categoría (IA, Programación, DevOps, etc.), tipo (Tech/Beca/RSS), fuente RSS específica, canal, semana
- **Chips con favicon:** cada chip de canal/fuente muestra avatar o favicon via Google S2 (`//www.google.com/s2/favicons?domain=...`)
- **Ranking GitHub Stars:** top 20 repos ordenados por estrellas extraídos de GitHub Topics/Collections, con filtro por nombre/lenguaje
- **Badges con clases CSS unificadas:** `.badge-tech`, `.badge-beca`, `.badge-rss`, `.badge-cat`

### Telegram con Audio por Noticia

`send_telegram.py` envía cada noticia nueva como mensaje separado con:
- Resumen IA de 3-4 líneas generado por Gemini
- Botón inline al dashboard
- Audio TTS con edge-tts (voz `es-ES-AlvaroNeural`)
- Control de duplicados vía `telegram_sent.json`

## 4. Desglose del Feature Set

- **139 fuentes monitorizadas:** YouTube, blogs tech, RSS, Twitter, GitHub, Product Hunt
- **Clasificación inteligente:** 7 categorías (IA, Programación, DevOps, Ciberseguridad, Hardware, Negocios, Becas) + badges Tech/Beca/RSS
- **Dashboard interactivo:** filtros combinables por categoría + tipo + fuente RSS + canal + semana, ranking GitHub Stars
- **Newsletter diaria:** resúmenes individuales por noticia con Gemini, estadísticas rápidas
- **Telegram cada 30 min:** notificaciones con resumen IA + audio TTS, dedup entre envíos
- **Ranking GitHub Stars:** top 20 repos ordenados por estrellas desde GitHub Topics/Collections
- **Deduplicación:** por URL normalizada y título similar en scrape y generación de dashboard
- **SEO:** meta tags Open Graph, Twitter Cards, JSON-LD WebSite

## 5. Puesta en Marcha Local

```bash
git clone https://github.com/jorbencas/test_githubActions.git
cd test_githubActions
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Scrapear noticias
python scrape_news.py

# Scrapear herramientas
python scrape_tools.py

# Generar dashboard
python generate_weekly.py

# Enviar Telegram (dry-run)
python send_telegram.py --dry-run --max-items 3

# Enviar email (dry-run)
python send_email.py --dry-run --max-items 5
```

El dashboard se genera en `public/index.html` y se puede previsualizar con `python -m http.server -d public`.
