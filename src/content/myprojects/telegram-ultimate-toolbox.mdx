Tengo canales de Telegram donde comparten archivos importantes: documentos, vídeos, cursos, herramientas. Pero Telegram no tiene forma de descargar todo el contenido de un canal de golpe. Tienes que ir archivo por archivo, y si el canal tiene miles de mensajes, es una eternidad.

**Mi motivación:** Un día necesitaba respaldar un canal entero que estaba a punto de ser eliminado. Tenía cientos de archivos útiles y no quería perderlos. Empecé a descargar uno por uno y me di cuenta de que iba a tardar horas (o días). Además, algunos canales están en otros idiomas y necesitaba traducir los mensajes automáticamente.

También quería vigilar ciertos canales en tiempo real para recibir alertas cuando apareciera contenido relevante (ofertas de trabajo, descuentos, noticias). Y, con el tiempo, también quería **subir vídeos a varios grupos de Telegram de forma automática** cuando no estoy delante del ordenador. Pero Telegram no tiene esa función de alertas por palabras clave ni un uploader multi-grupo.

Así que hice **Telegram Ultimate Toolbox**: un script con cuatro módulos que resuelven todos estos problemas.

---

## El problema

Telegram no ofrece una forma nativa de descargar grandes volúmenes de contenido, traducir automáticamente los mensajes, vigilar canales con alertas personalizadas ni subir vídeos a varios grupos de golpe. Las herramientas existentes suelen ser limitadas, poco seguras o no manejan bien las restricciones de canales protegidos.

## La solución

Un script Python con TelegramClient (Telethon) que ofrece cuatro módulos principales: descarga masiva, clonación con traducción, vigilante de contenido y subidor automático a grupos. Las credenciales se almacenan cifradas con AES (Fernet) y el sistema de logs muestra el progreso con iconos coloreados por tipo de mensaje.

## Los 4 módulos

### 1. Descarga Masiva

Descarga contenido de canales de Telegram de tres formas:

| Método | Descripción | Uso |
|--------|-------------|-----|
| **Enlace Único** | Pegas un enlace directo | Para archivos sueltos |
| **Rango de IDs** | Usa `enlaces.txt` con IDs | Para rangos específicos |
| **Procesar enlaces.txt** | Lee todos los enlaces del archivo | Para descarga masiva |

El módulo maneja:
- Resolución de canales con caché (`peer_cache`)
- Descarga robusta con resume (archivos `.part`)
- Progreso en tiempo real por archivo
- Filtro de spam automático
- Traducción opcional de textos detectados

```python
async def download_media_robust(client, message, folder):
    # Archivo temporal .part para resume
    temp_path = full_path + ".part"
    if os.path.exists(full_path):
        return True  # Ya existe, saltar
    
    with open(temp_path, 'wb') as f:
        await client.download_media(message, file=f, progress_callback=prog)
    os.rename(temp_path, full_path)
```

### 2. Clonación & Backup

Clona mensajes de un canal a otro con opciones avanzadas:

```
ID/Username del canal ORIGEN: @canal_origen
ID/Username del canal DESTINO: @canal_destino
¿Cuántos mensajes clonar?: 100
¿Descargar multimedia también? (s/n): s
¿Traducir contenido al clonar? (s/n): s
```

Características:
- **Traducción automática**: Traduce el contenido al clonar usando `mtranslate`
- **Descarga de multimedia**: Opción de descargar archivos adjuntos
- **Filtro de spam**: Salta mensajes que contengan palabras de la lista negra
- **Límite configurable**: Puedes clonar N mensajes específicos
- **Velocidad controlada**: Sleep de 0.8s entre mensajes para evitar rate limits

### 3. Modo Vigilante

Monitorea canales en tiempo real y envía alertas cuando detecta contenido relevante:

```
Palabras clave extra (separadas por coma): bitcoin, invertir, urgente
```

El vigilante:
- Escucha `events.NewMessage` en tiempo real
- Aplica el filtro de spam automático
- Compara con las palabras clave personalizadas
- Envía alertas a "me" (mensajes guardados) de Telegram
- Se detiene con `Ctrl+C`

```python
@client.on(events.NewMessage)
async def handler(event):
    texto = event.message.message
    if procesar_texto_inteligente(texto) == "FILTERED_CONTENT" or \
       any(p in texto.lower() for p in palabras):
        await client.send_message('me', f"🔔 Alerta Vigilante:\n{texto}")
```

### 4. Modo Uploader (`subir_videos.py`)

Sube vídeos comprimidos a **varios grupos** de Telegram automáticamente. Es la última pieza del pipeline **"Grabar → Comprimir → Subir a Telegram"**: vigila una carpeta y por cada `*_compressed.mp4` lo envía a todos los grupos de `grupos.json`.

```bash
# Setup de sesión (una vez, crea uploader.session)
docker compose run --rm uploader python /app/subir_videos.py --setup

# Descubrir tus chats/grupos (copia los IDs a grupos.json)
docker compose run --rm uploader python /app/subir_videos.py --list-chats

# Modo automático (bucle, sube cada intervalo)
docker compose up -d uploader
```

Características:
- **Varios grupos**: definidos en `grupos.json` (acepta IDs numéricos con `-` para grupos/canales y `@usernames`).
- **Sesión propia**: usa `uploader.session`, separada de la sesión del menú interactivo (`ultimate_session`). Así puedes correr el menú de descargas y el uploader **a la vez** sin conflictos.
- **Límite de 2 GB**: si un vídeo supera 2 GB, lo divide en partes con `ffmpeg -c copy` (sin recompresión) antes de subir.
- **Registro de enviados** (`enviados.json`): no reenvía lo ya subido y elimina el original al completar.
- **Robusto**: maneja credenciales corruptas, `grupos.json` mal formado, sesión vencida (sugiere `--setup`) y fallos por grupo sin marcar como enviado.
- **Configurable por entorno** (`UPLOADER_API_ID`, `UPLOADER_INTERVALO`, `UPLOADER_CARPETAS`, `UPLOADER_SESION`, `UPLOADER_GRUPOS`, `UPLOADER_ENVIADOS`, `UPLOADER_PARTES`...).

```json
// grupos.json
{
    "grupos": [
        "@mi_grupo_publico",
        -1001234567890
    ]
}
```

## Seguridad: cifrado AES

Las credenciales de la API de Telegram se almacenan cifradas con Fernet (AES-CBC):

### Flujo de cifrado

```
1. Usuario introduce API ID y API HASH
2. Se genera una llave Fernet (si no existe secret.key)
3. Los datos se cifran con Fernet.encrypt()
4. Se guardan en config.bin (binario)
5. La llave se guarda en secret.key (NUNCA commitear)
```

### Flujo de descifrado

```python
key = open("secret.key", "rb").read()
cipher = Fernet(key)
with open("config.bin", "rb") as f:
    datos_cifrados = f.read()
    datos_planos = cipher.decrypt(datos_cifrados).decode('utf-8')
    config = json.loads(datos_planos)
```

### Archivos importantes

| Archivo | Contenido | Protección |
|---------|-----------|------------|
| `config.bin` | API ID y Hash cifrados | No commitear |
| `secret.key` | Llave de cifrado | **NUNCA commitear** (si lo borras, pierdes acceso) |
| `ultimate_session.token` | Token de persistencia | No commitear |

## Filtro de spam

Lista negra predefinida que se aplica automáticamente:

```python
SPAM_LIST = [
    "crypto", "ganar dinero", "casino", "poker", 
    "estafa", "bet", "sex", "porn", "gore", "nude"
]
```

El filtro se aplica en:
- Descarga masiva: salta mensajes que contengan estas palabras
- Clonación: no clona contenido filtrado
- Vigilante: marca como alerta si detecta contenido filtrado

## Peculiaridades

- **Auto-setup**: Instala dependencias automáticamente si faltan
- **Resume de descargas**: Si se interrumpe, continúa desde donde quedó (archivos `.part`)
- **Caché de canales**: Resuelve entidades de canales una sola vez y las reutiliza
- **Rate limit controlado**: Sleep de 0.8s entre mensajes para no ser bloqueado
- **2FA soportado**: Maneja automáticamente la verificación en dos pasos
- **Sesión persistente**: No necesita re-login entre ejecuciones
- **Uploader multi-grupo**: Sesión propia (`uploader.session`), sin conflictos con el menú interactivo
- **División >2 GB**: Corta vídeos grandes en partes con `ffmpeg -c copy` antes de subir
